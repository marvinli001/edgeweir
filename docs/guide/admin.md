# 平台管理

平台管理员的后台：集群与节点、区域、组织与用户、审计日志、系统设置及其他平台级配置。

## 平台管理员

平台管理员是账户级角色（better-auth `admin` 角色），与组织内的 **管理员** 角色无关。

| 来源 | 说明 |
| --- | --- |
| 初始化向导 | 创建第一个平台管理员 |
| **后台 → 组织与用户 → 用户** | **新建用户** 时开启 **平台管理员**，或对已有用户 **设为平台管理员** / **取消平台管理员** |

| 权限 | 说明 |
| --- | --- |
| 后台 | 访问 `/admin/*`；其他用户访问时跳转到 `/overview`，对应 API 返回 403 |
| 跨组织查看 | 控制台 **网站** 列出所有组织的网站，显示 **组织** 与 **集群** 列；有多个集群时可按集群筛选 |
| 所属组织 | 在所属组织中按所有者处理；控制台中新建的资源归属当前组织，不属于任何组织时不能在控制台新建网站 |
| 集群选择 | 新建网站时可指定集群（`/api/v1` 的 `clusterId`）；界面新建的网站落在组织默认集群 |
| 域名归属 | 平台管理员新建网站的域名免 TXT 校验；对待验证域名可点击 **免验证并发布**，见 [验证域名归属](dns-and-alerts.md#验证域名归属) |
| 两步验证策略 | 不受组织的 **要求成员启用两步验证** 约束 |

组织角色与账户安全见 [组织、成员与账户安全](organizations.md)。

## 控制台与后台切换

平台管理员的顶栏显示分段切换 **控制台 | 后台**：**控制台** 进入 `/overview`，**后台** 进入 `/admin`。其他用户不显示该切换。后台侧边栏：

| 菜单 | 路径 | 内容 |
| --- | --- | --- |
| **平台概览** | `/admin` | 集群、节点、最近发布与全平台统计 |
| **集群与节点** | `/admin/clusters` | 集群、节点组、节点、节点升级、配置版本 |
| **告警渠道** | `/admin/alerts` | 通知渠道与告警规则 |
| **平台 DNS** | `/admin/dns` | DNS 服务商、DNS 配置与 DNS 版本 |
| **平台规则** | `/admin/rules` | 作用于所有网站的规则 |
| **平台 IP 名单** | `/admin/ip-lists` | 平台级 IP 名单 |
| **封禁** | `/admin/bans` | 全部组织的封禁与平台封禁 |
| **区域** | `/admin/regions` | 节点组的区域标签 |
| **组织与用户** | `/admin/organizations` | 组织、成员、用户账户 |
| **审计日志** | `/admin/audit` | 全部管理操作记录 |
| **系统设置** | `/admin/settings` | 系统信息与平台级设置 |

## 平台概览

| 区块 | 内容 |
| --- | --- |
| **集群** | 集群数；每个集群的在线节点数 / 节点总数 |
| **节点** | 在线节点数 / 节点总数；按状态排序：**离线**、**应用失败**、**落后**、**待同步**、**已停用**、**已同步**。无节点时显示 **添加节点** |
| **最近发布** | 全部集群最近的配置版本及原因 |
| **统计** | 全平台流量，时间范围 1 小时至 30 天；**流量最高的网站**、**流量最高的节点** |

页面每 10 秒刷新。

## 集群与节点

页面顶部为 **新建集群**、**添加节点** 与当前集群的概要（**在线节点**、**网站**、**最新版本**）。有多个集群时用 **选择集群** 切换。

### 集群

集群是一组节点与分配到这些节点的网站；每个集群有独立的配置版本序列。

| 操作 | 说明 |
| --- | --- |
| **新建集群** | **集群名称**：小写字母、数字与 `-`，以字母或数字开头，最多 64 字符，平台内唯一；**描述**：最多 500 字符。创建时生成默认节点组 `default` 并发布版本 #1 |
| **编辑集群** | 修改名称与描述 |
| **删除** | 仅当集群没有节点和网站时允许 |

一个集群最多发布 512 个网站。

### 节点组

| 操作 | 说明 |
| --- | --- |
| **新建节点组** | **节点组**：名称，最多 64 字符，集群内唯一；**区域**：可选，见 [区域](#区域)；**金丝雀组**：见 [配置金丝雀](#配置金丝雀) |
| **编辑节点组** | 修改名称、区域与 **金丝雀组** |
| 删除 | 默认节点组（标记 **默认**）不能删除；删除其他节点组时，其中节点移回默认节点组 |

节点组用于平台 DNS 线路、节点升级的试运行组与配置金丝雀。

### 添加节点

**添加节点** 生成一次性安装命令。

| 字段 | 说明 |
| --- | --- |
| **节点名称** | 可选，最多 64 字符 |
| **节点组** | 默认为集群的默认节点组 |
| **有效期** | 15 分钟、1 小时（默认）、24 小时；API 允许 5 分钟至 7 天 |

结果：**安装命令**（仅显示一次，带剩余时间）与 **CA 指纹**。token 以 `ewt_` 开头，单次有效；数据库保存其 SHA-256 与前缀，不保存明文。安装流程见 [接入节点](../deploy/nodes.md)。

### 节点

| 列 | 内容 |
| --- | --- |
| **节点** | 名称与主机名 |
| **状态** | **在线**（45 秒内有心跳）、**离线**、**已停用** |
| **节点组** | 节点组与区域 |
| **IP** | 节点上报的地址 |
| **已应用版本** | 节点已应用的配置版本；标记 **已同步**（达到该节点的目标版本）、**落后**、**应用失败**（悬停显示原因）或 **需要升级** |
| **Agent / 引擎** | agent 版本、引擎及其版本 |
| **心跳** | 最近一次心跳时间 |

| 操作 | 说明 |
| --- | --- |
| **改名** | 最多 64 字符 |
| **移动到节点组** | 仅限同一集群的节点组 |
| **停用** / **启用** | 停用后节点通道拒绝该节点，节点继续按最后一次成功应用的配置服务；其未完成的刷新预热任务标记为 **已跳过**，重新启用并拉取任务时补发整站刷新 |
| **删除** | 吊销节点证书；节点须用新的安装命令重新注册 |

### 节点升级

**节点升级** 区块按节点组试运行并推进签名升级，见 [节点升级](node-upgrades.md)。

### 配置金丝雀

**配置金丝雀** 卡片按集群设置策略，并显示当前发布的状态。默认关闭。

| 策略字段 | 取值 | 默认值 |
| --- | --- | --- |
| **启用金丝雀** | 开 / 关 | 关 |
| **观察窗口（分钟）** | 1–60 | 5 |
| **通过后自动推进** | 开：窗口通过后推进到全部节点；关：等待管理员 **立即推进到全部** | 开 |
| **5xx 比例倍数（相对基线）** | 1–100 | 2 |
| **5xx 比例下限（%）** | 0.1–100 | 5 |
| **最小请求数** | 1–1000000 | 100 |

| 项目 | 行为 |
| --- | --- |
| 金丝雀节点 | 窗口开始时在线、属于 **金丝雀组** 的已启用节点。窗口结束前不变：期间离开金丝雀组的节点仍是金丝雀节点，新加入的节点等下一个窗口 |
| 目标版本 | 金丝雀节点取候选版本，其他节点取稳定版本；节点只会拿到自己的目标版本，不会拿到更新的版本 |
| DNS | 每个节点按自己的目标版本判断；窗口期间非金丝雀节点不被摘除 |
| 回滚条件（窗口内任一条） | 金丝雀节点应用失败；数据面不健康或离线；金丝雀节点的 5xx 比例超过 max(非金丝雀节点的 5xx 比例 × 倍数, 下限)，且金丝雀请求数不少于最小请求数；窗口结束后超过一个窗口仍未应用 |
| 回滚动作 | 以稳定版本的内容发布一个新版本，所有节点回到该内容，但不带回窗口内停用、暂停、删除的网站和移除的域名，缓存代数与证书取当前值；写审计（系统身份）并发出平台告警「配置金丝雀发布已回滚」 |
| 回滚后 | 集群停在稳定版本。数据库里的改动不撤销，之后的发布仍然先经过金丝雀 |
| 窗口期间有新发布 | 新候选版本取代旧候选版本，窗口的开始时间和金丝雀节点不变 |
| 没有在线的金丝雀节点 | 直接发布到全部节点，写审计 `cluster.rollout_direct` 并发出平台告警，不阻塞发布 |
| 直接到全部节点的变更 | ACME HTTP-01 挑战；停用、暂停、删除网站与移除域名；网站的 **清除缓存**；证书续签；挑战密钥轮换；网站与平台的 **Under Attack**。这些变更同时进入稳定版本，其余改动仍在候选版本里等待窗口。**配置版本** 的 **回滚** 也直接到全部节点 |
| 关闭策略 | 正在进行的候选版本推进到全部节点 |

| 状态 | 含义 |
| --- | --- |
| **未进行** | 没有候选版本 |
| **金丝雀中** | 候选版本在金丝雀节点上观察 |
| **等待推进** | 窗口已通过，等待管理员推进 |
| **已推进** | 候选版本已是全部节点的版本 |
| **已回滚** | 金丝雀节点已回到稳定版本 |
| **已直接发布** | 没有在线的金丝雀节点，变更已直接发布 |

**立即推进到全部**（写审计 `cluster.rollout_promote`）与 **中止并回滚**（写审计 `cluster.rollout_abort`）都需要确认，只在 **金丝雀中** 与 **等待推进** 时可用。策略修改写审计 `cluster.rollout_policy_update`。

### 配置版本

每次影响节点配置的变更在集群内发布一个新版本。**配置版本** 表列出最近 20 个版本：**版本**、**内容哈希**、**网站**、**原因**、**时间**。

| 原因 | 触发 |
| --- | --- |
| 创建集群 {集群} | 新建集群 |
| 新建网站 / 修改网站 / 删除网站 {网站} | 网站变更 |
| 清除网站 {网站} 的缓存 | 网站 **清除缓存** |
| 已更新 {网站} 的证书配置 | HTTPS 设置变更；网站引用的证书签发或续期完成 |
| 已更新 ACME 验证 | HTTP-01 挑战变更 |
| 已更新规则与 IP 名单 | 规则或 IP 名单变更 |
| 域名已验证 / 域名验证已撤销 | 域名归属变更 |
| 更新源站地址允许清单 | [源站地址允许清单](#源站地址允许清单) 变更，所有集群各发布一个版本 |
| 回滚到 #{版本} | **回滚** |
| 启用网站 / 停用网站 / 暂停网站 / 恢复网站 {网站} | 网站状态变更 |
| 版本 #{版本} 的金丝雀发布已回滚 | [配置金丝雀](#配置金丝雀) 回滚 |

**回滚** 以所选版本的内容发布一个新版本，不删除历史。回滚引用的证书、域名等资源已移除、转移或不可用时拒绝回滚；未验证的域名不能通过回滚恢复。

## 告警渠道

通知渠道（Webhook、邮件、钉钉、企业微信、Telegram）与 **告警规则**（离线阈值、证书到期预警、最低请求数、统计窗口、5xx 阈值）。每个渠道可设置 **通知语言**、**接收所有网站的告警**、**允许租户订阅**，并可 **发送测试**、**启用** / **停用**、**更新渠道凭据**。邮件渠道使用 [SMTP](#smtp) 设置。详见 [配置告警渠道](dns-and-alerts.md#配置告警渠道)。

## 平台 DNS

**DNS 服务商**（Cloudflare、阿里云、华为云、DNSPod）、**DNS 配置**（CNAME 域、TTL、线路到节点组的映射、目标地址）与 **DNS 版本**（**回滚 DNS**、**修复记录**）。配置后网站 **域名** 页显示 **CNAME 目标**。详见 [配置平台 DNS](dns-and-alerts.md#配置平台-dns)。

## 平台规则与平台 IP 名单

| 页面 | 内容 |
| --- | --- |
| **平台规则** | 作用于所有网站的规则；每个阶段先执行平台规则，再执行网站规则 |
| **平台 IP 名单** | 平台级 IP 名单，**动作** 为 **供规则引用**、**拦截** 或 **放行**；拦截与放行名单作用于所有网站，先于规则执行 |

表达式、阶段与名单上限见 [规则、IP 名单与 GeoIP](rules.md)。

## 封禁

**后台 → 封禁** 列出全部组织的有效封禁与平台封禁，可按范围、网站与来源筛选。**新建封禁** 的「范围」为「平台」时作用于所有网站，并在具备 `kernel-ban-v1` 的节点上由内核丢包；为「网站」时选择任一组织的网站。封禁规则、权限与内核封禁的启用方法见 [封禁](bans.md)。

## 区域

区域是节点组的标签（如华东），在节点组与节点表中显示。

| 操作 | 说明 |
| --- | --- |
| **新建区域** | **名称**：最多 64 字符；**代码**：小写字母、数字与 `-`，以字母或数字开头，最多 32 字符，平台内唯一 |
| **编辑区域** | 修改名称与代码 |
| 删除 | 引用该区域的节点组保留，区域置空 |

## 网站

**后台 → 网站** 列出全部组织的网站，可搜索。

| 操作 | 说明 |
| --- | --- |
| **暂停** | 选择 **原因**（费用、滥用、安全、其他），可填 **备注**（最长 256 字符，只有平台管理员与服务账号能看到）。暂停的网站不下发到节点，DNS 记录保留；组织成员看到本地化的原因，不能解除 |
| **恢复** | 需要确认 |

暂停与恢复写审计（`site.suspend`、`site.resume`），并发布配置版本。行为见 [网站启停与平台暂停](organizations.md#网站启停与平台暂停)。

## 服务账号

**后台 → 服务账号** 管理供集成调用 `/api/v1` 的服务账号：名称、scope、启用状态、key 的创建与吊销（key 只显示一次）。scope 与可调用的过程见 [服务账号](../reference/api.md#服务账号)。

## 组织与用户

页面分 **组织** 与 **用户** 两个页签。

### 组织

| 操作 | 说明 |
| --- | --- |
| **新建组织** | **组织名称**：最多 100 字符；**标识**：留空则按名称生成，小写字母、数字与 `-`，最多 48 字符，平台内唯一；**默认集群**：留空为 **最早的集群**；**要求成员启用两步验证** |
| **编辑** | 修改名称、默认集群与两步验证策略 |
| **成员** | 打开 **{组织} 的成员**：**添加用户**（选择已有用户与角色）、**邀请成员**（生成邀请链接）、修改角色、移除 |
| **限额** | 每项限额与当前用量；留空为不限，见 [技术限额](organizations.md#技术限额) |

平台管理员在任意组织中按所有者权限管理成员，包括所有者。组织不能删除。成员与邀请规则见 [组织、成员与账户安全](organizations.md#邀请与成员管理)。

### 用户

| 操作 | 说明 |
| --- | --- |
| 搜索 | 按姓名或邮箱，最多返回 500 个用户 |
| **新建用户** | **姓名**、**邮箱**、**密码**（12–128 字符）；可选加入一个组织并指定 **角色**；可选 **平台管理员** |
| **设为平台管理员** / **取消平台管理员** | 不能取消自己的平台管理员角色 |
| **停用账号** / **启用账号** | 停用时删除该用户全部会话，停用期间其登录与 AccessKey 调用被拒绝；不能停用自己 |

用户不能删除。

## 审计日志

所有管理操作写入审计日志。控制台自身的变更与审计条目在同一事务中提交；登录、修改密码、两步验证、通行密钥与 AccessKey 的变更由 better-auth 完成，审计条目在其提交后写入，写入失败只记录日志。审计日志不自动清理。

| 字段 | 内容 |
| --- | --- |
| 时间 | 操作时间 |
| 操作者 | 类型（**用户**、**AccessKey**、**服务账号**、**节点**、**系统**）、ID、名称 |
| IP、User-Agent | 请求来源；只存于数据库表 `audit_log`，界面与 API 不返回。IP 取值规则见 [可信代理与客户端 IP](../deploy/networking.md#可信代理与客户端-ip) |
| 组织 | 所属组织（如有） |
| 操作 | 形如 `site.create` |
| 对象 | 类型、ID、名称；名称在操作时记录，对象删除后仍可读 |
| 元数据 | JSON，操作相关的参数与前后值 |

页面显示 **时间**、**操作者**、**操作**、**对象**，每页 50 条；筛选 **操作**、**对象** 类型与时间范围（**全部时间**、**近 1 小时**、**近 24 小时**、**近 7 天**、**近 30 天**）。`/api/v1` 读取方式见 [API 与端点](../reference/api.md)。

| 操作前缀 | 内容 |
| --- | --- |
| `system.*` | 初始化（含 setup token 错误的 `system.setup_rejected`）、源站地址允许清单、节点发布源、所有权校验 DNS、用量设置、封禁设置 |
| `auth.*` | 登录成功（`auth.sign_in`，含登录方式）与失败（`auth.sign_in_failed`） |
| `account.*` | 修改密码、启用 / 停用两步验证、添加 / 删除通行密钥 |
| `api_key.*` | AccessKey 创建、删除、吊销 |
| `service_account.*` | 服务账号与其 key |
| `user.*`、`organization.*`、`member.*`、`invitation.*` | 用户、组织、成员与邀请 |
| `cluster.*`、`node_group.*`、`region.*`、`node.*`、`enrollment_token.*` | 集群（含配置金丝雀）、节点组、区域、节点（含注册、证书续期、升级）、安装命令 |
| `site.*`、`cache.*`、`domain.*`、`certificate.*`、`dns_credential.*`、`ip_list.*`、`platform.*` | 网站、刷新预热、域名归属、证书、DNS 凭据、IP 名单、平台规则 |
| `ban.*` | 手动封禁：`ban.create`、`ban.update`（再次封禁）、`ban.delete`（解封） |
| `dns.*`、`alert.*` | 平台 DNS（含大面积摘除保护与强制发布）、告警渠道、告警规则、SMTP、告警订阅 |

## 系统设置

### 系统信息

只读。

| 项目 | 来源 |
| --- | --- |
| **版本** | 镜像版本 `<YYYYMMDD>-<commit>`；源码运行为 `dev` |
| **控制台地址** | `EDGEWEIR_PUBLIC_URL` |
| **节点通道** | `EDGEWEIR_NODE_API_URL`；未设置时为 `https://<EDGEWEIR_PUBLIC_URL 的主机名>:<NODE_API_PORT>` |
| **CA 指纹** | 节点通道内部 CA 的 SHA-256；安装命令中的 `--ca-sha256` 与之相同 |
| **统计模式** | `EDGEWEIR_ANALYTICS`（`lite` / `clickhouse`） |
| **遥测** | `EDGEWEIR_TELEMETRY`；默认 **关闭** |
| **Setup token** | **未使用** 或 **已于 {时间} 使用** |
| **OpenAPI** | `/api/v1/openapi.json` |

### 源站地址允许清单

**允许的地址段（每行一个 CIDR）**，最多 256 条。清单内的内网、回环等特殊用途地址对所有组织的源站开放。保存后所有集群各发布一个配置版本，并写审计日志。源站地址规则见 [源站地址限制](origins-and-cache.md#源站地址限制)。

### 节点发布源

**发布源地址**：节点升级读取发布清单的镜像地址，布局为 `<地址>/v<版本>/checksums.txt`。

| 约束 | 说明 |
| --- | --- |
| 格式 | `http(s)` URL，不含账号、查询参数或片段 |
| 协议 | 公网地址须使用 HTTPS；HTTP 只用于 `EDGEWEIR_OUTBOUND_ALLOW_CIDRS` 放行的内网地址 |
| 出站策略 | 保存时解析主机名，地址须为公网或 `EDGEWEIR_OUTBOUND_ALLOW_CIDRS` 放行的地址 |
| 清空 | 保存空值后回退到环境变量或默认值 |

每个节点另有本机固定的发布源与签名信任锚，控制台不能修改；见 [节点升级](node-upgrades.md)。

### 所有权校验 DNS

**递归 DNS 服务器**：域名归属 TXT 校验使用的递归服务器，最多 8 个。格式为 IP、`IPv4:端口`、`[IPv6]:端口` 或主机名（可带端口），默认端口 53。保存时解析并固定地址，地址须为公网或 `EDGEWEIR_OUTBOUND_ALLOW_CIDRS` 放行的地址。只填写可信的递归服务器：查询结果决定域名归属。输入框为空时，占位文字显示当前生效的服务器或 **系统解析器**。

### 用量

| 字段 | 取值 | 默认值 | 说明 |
| --- | --- | --- | --- |
| **保留天数** | 35–400 | 100 | 用量记录保留时间 |
| **离线节点不阻塞完整性（分钟）** | 5–1440 | 60 | 超过该时间没有心跳的节点不再阻塞 `completeUntil` |

修改写审计 `system.usage_update`。用量接口与 `completeUntil` 的定义见 [用量](../reference/api.md#用量)。

### 封禁

| 字段 | 取值 | 默认值 | 说明 |
| --- | --- | --- | --- |
| **平台手动封禁上限** | 100–100000 | 10000 | 全平台有效的手动封禁（平台与网站）总数；超出返回 `BAN_PLATFORM_LIMIT` |
| **集群内共享自动封禁** | 开 / 关 | 开 | 节点产生的自动封禁是否下发到同集群的其他节点；关闭时只保存供查看 |

修改写审计 `system.bans_update`。见 [封禁](bans.md)。

### 防护

| 字段 | 取值 | 默认值 | 说明 |
| --- | --- | --- | --- |
| **平台 Under Attack** | 开 / 关 | 关 | 所有网站没有通行凭证的 GET/HEAD 请求先挑战；切换前需确认，保存后所有集群各发布一个配置版本 |
| **挑战类型** | Cookie 跳转 / JS 计算 / 工作量证明 / 图片验证码 | JS 计算 | 平台 Under Attack 的挑战类型 |
| **安全事件保留天数** | 7–365 | 30 | 节点上报的 CC 防护事件保留时间 |

修改写审计 `system.protection_update`。平台 Under Attack 需要节点能力 `challenge-v1`；平台管理员的发布不受租户能力检查限制，缺少能力的节点保留原配置。

### OWASP CRS

| 字段 | 取值 | 默认值 | 说明 |
| --- | --- | --- | --- |
| **允许租户开启 OWASP CRS** | 开 / 关 | 开 | 关闭后租户不能开启或修改运行中的 CRS，只能关闭；已开启的网站保持运行，平台管理员不受限制 |

保存不发布配置；修改写审计 `system.waf_update`。见 [OWASP CRS 托管规则](waf.md)。

### 平台错误页

| 字段 | 适用的请求 | 说明 |
| --- | --- | --- |
| **未知域名** | Host 不属于集群的任何网站 | 状态码 404；留空使用内置页面 |
| **网站已停用** | 已停用网站的已验证域名 | 状态码 503 |
| **网站已暂停** | 被平台暂停的网站的已验证域名 | 状态码 503 |

每个模板最多 65536 字节（UTF-8），占位符 `{{status}}`、`{{request_id}}`、`{{client_ip}}`、`{{host}}` 的值经 HTML 转义。保存后所有集群各发布一个配置版本（原因「修改平台错误页」）；修改写审计 `system.error_pages_update`。旧节点忽略平台错误页。见 [错误页](error-pages.md#平台错误页)。

### CC 模板

网站开启 CC 防护并「跟随平台模板」时使用的阈值：最高级别、验证码级别改用高难度计算验证、窗口、站点 QPS、单 URL QPS、单 IP QPS、IP 封禁时长、源站错误率、最小回源请求数、持续多久升级、冷却多久降级。字段、范围与默认值见 [CC 防护](challenges.md#cc-防护)。保存后，有网站跟随模板的集群各发布一个配置版本；修改写审计 `system.cc_template_update`。

### GeoIP 数据库

只读。逐个节点显示 **国家**、**省份** 与 **ASN** 数据状态（**可用** / **未配置**），并带 IPinfo 署名链接。国家和 ASN 数据随节点发布镜像内置，其余数据库由各节点本机配置；**配置数据库** 链接到 [规则、IP 名单与 GeoIP](rules.md)。

### SMTP

邮件告警渠道的发信服务器。

| 字段 | 默认值 | 说明 |
| --- | --- | --- |
| **SMTP 主机** | 无 | 最多 253 字符 |
| **SMTP 端口** | 465 | 1–65535 |
| **直接 TLS（关闭时使用 STARTTLS）** | 开启 | 关闭时要求 STARTTLS；证书校验始终开启 |
| **发件地址** | 无 | 邮箱地址 |
| **SMTP 用户名** | 无 | 必填 |
| **SMTP 密码** | 无 | 主密钥信封加密后入库；留空保留现有密码 |
| **CA 证书（PEM）** | 空 | 仅含 PEM 证书；填写后替代系统信任库校验该服务器 |

| 约束 | 说明 |
| --- | --- |
| 更换目标 | 修改主机、端口、TLS 方式、用户名或 CA 证书时必须重新填写密码 |
| 出站策略 | 发信时解析并固定地址，内网地址须由 `EDGEWEIR_OUTBOUND_ALLOW_CIDRS` 放行 |

### 设置优先级

后台保存的值优先于环境变量，环境变量优先于默认值。环境变量只作为已有部署的后备。

| 设置 | 后台位置 | 环境变量 | 默认值 |
| --- | --- | --- | --- |
| 节点发布源 | **节点发布源** | `EDGEWEIR_NODE_RELEASE_BASE_URL` | `https://github.com/marvinli001/edgeweir-node/releases/download` |
| 所有权校验 DNS | **所有权校验 DNS** | `EDGEWEIR_DNS_RESOLVERS`（逗号分隔） | 系统解析器 |
| SMTP CA 证书 | **SMTP → CA 证书（PEM）** | `EDGEWEIR_SMTP_CA_FILE`（PEM 文件路径） | 系统信任库 |
| SMTP 服务器与账户 | **SMTP** | 无 | 未配置 |
| 源站地址允许清单 | **源站地址允许清单** | 无 | 空 |
| 用量 | **用量** | 无 | 保留 100 天，离线阈值 60 分钟 |
| 封禁 | **封禁** | 无 | 上限 10000，共享自动封禁 |

**节点发布源** 与 **所有权校验 DNS** 的标签显示当前生效值的来源：**后台设置**、**环境变量** 或 **默认**。后台保存的地址受 `EDGEWEIR_OUTBOUND_ALLOW_CIDRS` 约束；环境变量中的值由运维设置，不经该检查。全部环境变量见 [环境变量](../reference/environment.md)。

## 故障排查

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| **集群还有 N 个节点和 M 个网站，不能删除** | 集群非空 | 删除集群内的节点与网站后重试 |
| **集群名称已存在：…** / **节点组已存在：…** / **区域代码已存在：…** | 名称或代码重复 | 更换名称或代码 |
| **默认节点组不能删除** | 删除默认节点组 | 默认节点组只能改名或更换区域 |
| **节点组不属于该节点所在的集群** | 跨集群移动节点 | 节点只能在集群内移动；换集群须删除后重新注册 |
| **回滚引用的资源已移除、转移或不可用** | 目标版本引用的证书或域名已不可用 | 选择更近的版本，或修复当前配置 |
| **不能对自己执行这个操作** | 停用自己或取消自己的平台管理员角色 | 由其他平台管理员操作 |
| **邮箱已注册：…** | 新建用户的邮箱已存在 | 将已有用户加入组织 |
| **组织标识已存在：…** | 标识重复 | 更换标识 |
| **发布源须使用 HTTPS 并解析到允许的地址** | 公网 HTTP 地址，或解析到未放行的内网地址 | 使用 HTTPS，或在 `EDGEWEIR_OUTBOUND_ALLOW_CIDRS` 放行 |
| **DNS 服务器须解析到允许的地址** | 服务器解析到未放行的内网地址 | 改用公网服务器，或在 `EDGEWEIR_OUTBOUND_ALLOW_CIDRS` 放行 |
| **更换 SMTP 服务器或账户时需填写新密码** | 修改了 SMTP 目标但未填写密码 | 填写密码后保存 |
| **CA 证书须为 PEM 格式** | CA 证书字段含非证书内容 | 只粘贴 PEM 证书 |
