# 账户与登录

控制台唯一的运营者账户：初始化、登录、会话、账户安全、个人设置、控制台导航与找回账户。

## 账户

控制台只有一个账户，由初始化向导（`/setup`，**创建账户**）创建。

| 项目 | 说明 |
| --- | --- |
| 初始化字段 | **初始化令牌**（控制台日志中打印的一次性 setup token）、**姓名**（1–100 字符）、**邮箱**（登录邮箱）、**密码**（12–128 字符）。步骤见 [快速上手](first-site.md) |
| 其他账户 | 不开放注册；控制台没有用户管理，不能添加第二个账户。只读的演示账号由 [系统设置 → 演示账号](system.md#演示账号) 开关，不是第二个管理账户 |
| 姓名与邮箱 | 控制台不提供修改入口 |
| 密码 | 在 [账户安全](#账户安全) 修改；Web 界面不提供找回或重置密码的入口，忘记密码时在服务器上重置，见 [找回账户](#找回账户) |
| API | AccessKey（`ewk_` 开头）以该账户身份调用 `/api/v1`，在 [个人设置](#个人设置) 中创建 |

## 登录

页面：`/login`。

| 方式 | 说明 |
| --- | --- |
| 密码 | 填写 **邮箱** 与 **密码**，点击 **登录** |
| 两步验证 | 账户启用 TOTP 后，密码正确时进入 **两步验证**：输入 6 位验证码，或点击 **使用备用码** 输入备用码（**使用验证器** 切回验证码，**返回登录** 回到第一步）。该步骤 10 分钟内有效；同一步骤输错 5 次后须重新登录，连续 10 次验证失败后两步验证锁定 15 分钟 |
| 通行密钥 | 点击 **使用通行密钥登录**，不进入两步验证步骤。浏览器不支持 WebAuthn 时不显示 |
| 演示账号 | [演示账号](system.md#演示账号) 开启时显示 **使用演示账号登录** |

| 项目 | 说明 |
| --- | --- |
| 跳转 | 登录后回到登录前打开的页面，否则进入 **概览** |
| 登录限速 | 登录、两步验证（含 **账户安全** 中的启用与停用）与修改密码：每个客户端 IP 每 10 秒 3 次，生产环境（`NODE_ENV=production`）启用。客户端 IP 的取值见 [可信代理与客户端 IP](../deploy/networking.md#可信代理与客户端-ip) |
| 登录 IP 白名单 | 设置后只有名单内的地址能登录和使用会话，见 [登录 IP 白名单](system.md#登录-ip-白名单) |
| 审计 | 登录成功（`auth.sign_in`，含登录方式）与失败（`auth.sign_in_failed`）写入 [审计日志](system.md#审计日志) |

## 会话

| 项目 | 说明 |
| --- | --- |
| 有效期 | 7 天；使用期间每 24 小时最多顺延一次（better-auth 默认值） |
| 退出 | 顶栏的 [用户菜单](#用户菜单) → **退出登录** |
| 其他设备 | 控制台不列出会话；修改密码时其他设备上的会话退出登录，[找回账户](#找回账户) 时全部会话退出登录 |

## 账户安全

页面：用户菜单 → **账户安全**（`/security`）。

### 密码

| 项目 | 说明 |
| --- | --- |
| 修改 | 填写 **当前密码**、**新密码**、**确认新密码**，点击 **修改密码** |
| 长度 | 12–128 字符 |
| 其他会话 | 修改后其他设备退出登录 |

### 两步验证（TOTP）

1. 在 **两步验证（TOTP）** 中填写 **当前密码**，点击 **启用**。
2. 用验证器扫描二维码，或手动输入 **密钥**。
3. 输入 6 位 **验证码**，点击 **验证**。
4. 保存 **备用码**（仅显示一次）。

| 项目 | 说明 |
| --- | --- |
| 状态 | 卡片标题旁显示 **已启用** / **未启用** |
| TOTP 参数 | 6 位，30 秒，签发方 `Edgeweir` |
| 备用码 | 10 个，格式 `xxxxx-xxxxx`，每个仅可使用一次 |
| 重新生成备用码 | 停用后重新启用两步验证 |
| 停用 | 填写 **当前密码**，点击 **停用** |

### 通行密钥

| 项目 | 说明 |
| --- | --- |
| 添加 | 填写 **名称**（可选，最多 64 字符），点击 **添加通行密钥**，按浏览器提示完成注册。浏览器不支持 WebAuthn 时按钮不可用 |
| 删除 | 在列表中删除，需确认 |
| 绑定 | 通行密钥绑定 `EDGEWEIR_PUBLIC_URL` 的主机名；更换控制台主机名后，已注册的通行密钥无法使用 |

修改密码、启用与停用两步验证、添加与删除通行密钥写入 [审计日志](system.md#审计日志)（`account.*`）。

## 个人设置

页面：用户菜单 → **个人设置**（`/settings`）。

| 卡片 | 内容 |
| --- | --- |
| **偏好** | **语言**（简体中文 / English）与 **主题**（浅色 / 深色 / 跟随系统），保存在当前浏览器 |
| **AccessKey** | 创建、编辑与吊销 AccessKey，见下表 |

| AccessKey 字段 | 取值 | 说明 |
| --- | --- | --- |
| **名称** | 1–64 字符 | 创建后可在 **编辑密钥** 中修改 |
| **权限范围** | **只读** / **读写**，默认读写 | 只读密钥只能调用 GET 接口与 `rules.validate`；创建后不能修改 |
| **每分钟请求数** | 1–100000，默认 600；留空为不限 | 超出时 `/api/v1` 返回 429 `API_KEY_RATE_LIMITED`（「AccessKey 请求过于频繁，请 N 秒后重试」）；可在 **编辑密钥** 中修改 |

| 项目 | 说明 |
| --- | --- |
| 密钥 | `ewk_` 开头，仅在创建时显示一次 |
| 列表 | 每行显示名称、权限范围、每分钟请求数（「N 次/分钟」或「不限速」）、**已吊销** 与 **最后使用** |
| 会话要求 | 只能在已登录的控制台中创建与编辑，用 AccessKey 调用返回 403 `ACCESS_KEY_SESSION_REQUIRED`（「请登录控制台后创建或修改密钥」） |
| 审计 | `api_key.create`、`api_key.update`、`api_key.revoke` |

请求头、权限范围与限速见 [API 概览](../reference/api.md#accesskey)。

## 故障排查

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| **验证码错误** | 两步验证的验证码不正确 | 核对验证器设备的时间后重试，或改用备用码 |
| **验证已过期，请重新登录** | 两步验证步骤超过 10 分钟 | 重新登录 |
| **请求过于频繁，请稍后重试** | 触发登录限速；或同一次两步验证输错 5 次；或连续 10 次验证失败，两步验证锁定 15 分钟 | 限速时 10 秒后重试；输错 5 次时重新登录；锁定时 15 分钟后重试 |
| **此 IP 不在登录白名单内** | 当前地址不在 [登录 IP 白名单](system.md#登录-ip-白名单) 内 | 换到名单内的网络登录；名单已不含自己的任何地址时在服务器上清空，见 [找回账户](#找回账户) |
| **密码错误** | 修改密码、启用或停用两步验证时 **当前密码** 不正确 | 重新填写当前密码 |
| 通行密钥无法登录 | 控制台主机名已更换 | 用密码登录，删除旧通行密钥后重新添加 |
| 忘记密码 | Web 界面没有找回密码的入口 | 在服务器上重置密码，见 [找回账户](#找回账户) |
| 验证器设备与备用码都已丢失 | 无法完成两步验证 | 在服务器上停用两步验证，见 [找回账户](#找回账户)；登录后重新启用 |
| 更换 `BETTER_AUTH_SECRET` 后两步验证一直失败 | TOTP 密钥与备用码用原来的 secret 加密，新 secret 无法解密 | 改回原来的 `BETTER_AUTH_SECRET`；原值已丢失时在服务器上停用两步验证，见 [找回账户](#找回账户)，登录后重新启用 |

### 找回账户

无法登录时，在运行控制台的服务器上执行 `recover.js`，为唯一的账户重置密码、停用两步验证、清空 [登录 IP 白名单](system.md#登录-ip-白名单)，可以同时做多项。命令不经过 Web 界面，读取控制台容器的环境变量直接修改数据库。

1. 执行命令；只保留需要的选项（清空白名单时加 `--clear-login-allowlist`）：

   ```bash
   docker compose exec console node dist/server/recover.js --reset-password --disable-two-factor
   ```

   宝塔 / aaPanel 部署的容器名为 `edgeweir-console`：

   ```bash
   docker exec -it edgeweir-console node dist/server/recover.js --reset-password --disable-two-factor
   ```

2. 命令输出账户的姓名与邮箱。带 `--reset-password` 时，按提示输入两次新密码（12–128 字符），输入时不显示。
3. 命令输出完成的操作后，用账户邮箱登录；重置了密码时用新密码。
4. 停用了两步验证时，在 [账户安全](#账户安全) 重新启用，保存新的备用码。

| 项目 | 说明 |
| --- | --- |
| 会话 | 该账户的全部会话退出登录；已输入密码、尚未完成两步验证的登录失效 |
| 不变 | 姓名、邮箱、通行密钥与 AccessKey；怀疑账户被他人使用时，登录后检查并删除不认识的通行密钥与 AccessKey |
| 审计 | 写入 [审计日志](system.md#审计日志)：`account.recover`，操作者为 **系统**（`recover`） |

选项、从文件读取密码、输出与退出码见 [命令行](../reference/cli.md#找回账户)。
