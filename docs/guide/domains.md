# 域名与未知域名

网站「域名」页签，域名的四种写法与优先级，国际化域名，DNS 检查，未知域名与节点 IP 访问，扫描防护，CNAME 前缀。

## 概念

| 术语 | 定义 |
| --- | --- |
| 精确域名 | `a.com`、`www.a.com`：只匹配这个主机名。 |
| 泛域名 | `*.a.com`：匹配 `a.com` 下一级的任意主机名（`x.a.com`），不含多级（`y.x.a.com`）与 `a.com` 本身。 |
| 后缀域名 | `.a.com`：匹配 `a.com` 下任意层级的主机名（`x.a.com`、`y.x.a.com`），不含 `a.com` 本身。 |
| 正则域名 | `~` 加正则：对小写的 Host（不含端口）整串匹配。 |
| 国际化域名 | 含非 ASCII 字符的域名（`bücher.example`、`中国.example`），按 Punycode（`xn--…`）保存与匹配。 |
| 未知域名 | 请求的 Host 不属于集群的任何网站，或网站没有绑定请求到达的端口。 |
| 节点 IP 访问 | Host 为 IP 地址（`203.0.113.5`、`[2001:db8::1]`）或为空的请求。 |
| 默认网站 | 集群的一个已启用网站，未知域名或节点 IP 访问可以交给它。 |
| CNAME 前缀 | 网站与 L4 应用 CNAME 目标 `<前缀>.<集群域名>` 的第一段。 |
| 边缘地址 | 集群在线活动节点的主调度地址（配置了调度地址时用配置的地址，否则用节点上报的公网地址），即域名的 A / AAAA 记录应指向的地址。 |
| 解析状态 | 控制台当场解析网站域名的结果与集群节点地址的比较，见[解析状态](#解析状态)。 |

## 域名页签

页面：**网站 →（网站）→ 域名**（`/sites/<网站 ID>?tab=domains`），自上而下三张卡片：

| 卡片 | 内容 |
| --- | --- |
| 「CNAME 目标」或「边缘地址」 | 集群开启 [DNS 调度](dns.md)时为「CNAME 目标」，否则为「边缘地址」；下方是每个域名的[解析状态](#解析状态)，见 [CNAME 目标与边缘地址](#cname-目标与边缘地址) |
| 「域名」 | 网站的域名列表与添加框 |
| 「端口」 | 网站绑定的 HTTP 与 HTTPS 监听端口，见[网站端口](https.md#网站端口) |

### 编辑域名

1. 在「域名」卡片的输入框中填写一个或多个域名（以空格或逗号分隔，正则中的逗号不分隔），按回车或点击「添加域名」加入列表。写法见[域名写法](#域名写法)。
2. 点击域名右侧的删除按钮（「移除」）把它移出列表；只剩一个域名时不能删除。
3. 点击「保存」。输入框中尚未加入列表的域名一并保存。

- 保存即 `PATCH /api/v1/sites/{id}`（`domains` 整体替换）：所在集群发布新的配置版本（原因「修改网站 {site}」），写审计「修改网站」；提示「已保存」随节点更新，见[网站启停](clusters.md#网站启停)。
- 加入列表前在浏览器检查写法，不合法时提示「域名无效：…」。与列表中已有的域名重复（按保存形式比较，Unicode 与 Punycode 视为相同）的不再加入。
- 网站有证书时，新域名须被网站的某张证书覆盖；第一张证书是控制台申请且开启自动续期的证书时，证书加入新域名并重新签发（提示「证书 … 正在为新域名重新签发」）；其他情况保存失败，提示「证书域名与网站或 DNS 区域不匹配：…」（`CERTIFICATE_DOMAIN_MISMATCH`）。见[为 HTTPS 网站添加域名](https.md#为-https-网站添加域名)。
- 删除的域名同时从 HTTPS 的「不跳转的域名」中移除。

### CNAME 目标与边缘地址

| 状态 | 卡片 | 内容 |
| --- | --- | --- |
| 集群有 DNS 绑定（自动或手动模式） | 「CNAME 目标」 | `<CNAME 前缀>.<集群域名>` 与复制按钮；状态标记（下表）；绑定有解析线路时每条线路一行：线路名称与目标（打开「保留网站线路别名」时为 `<线路名称>.<CNAME 前缀>.<集群域名>`，否则为 `<线路名称>.<集群域名>`）；「重新生成」「自定义」与过渡期内的旧名称，见 [CNAME 前缀](#cname-前缀) |
| 集群没有 DNS 绑定 | 「边缘地址」 | 集群的边缘地址，每个地址标 `A` 或 `AAAA`，带复制按钮。有在线节点但都没有公网地址时为「无公网地址」，没有在线节点时为「没有在线节点」 |

| 「CNAME 目标」状态 | 条件 |
| --- | --- |
| 「已发布」 | 自动模式，集群最新的 DNS 版本已应用到 DNS 服务商，且包含该网站的 CNAME 记录 |
| 「无健康节点」 | 自动模式，已发布，但集群的汇总记录没有任何 A / AAAA 记录（节点都被健康摘除，见[健康摘除与修复](dns.md#健康摘除与修复)） |
| 「待发布」 | 自动模式，DNS 版本尚未应用，或该 CNAME 记录被[大面积摘除保护](dns.md#大面积摘除保护)暂缓 |
| 「手动」 | 手动模式：控制台不写记录，按 **集群与节点** 的 **DNS** 页签列出的记录自行创建，见[手动模式](dns.md#手动模式) |

- 「CNAME 目标」每 15 秒刷新，解析状态每 30 秒检查；卡片右上角的「重新检查」立即重新检查两者。
- 「边缘地址」卡片中，每个可检查的域名下方另有一条绕过 DNS 直接请求第一个边缘地址的命令，例如 `curl -sI --resolve www.example.com:443:203.0.113.5 https://www.example.com/`。网站证书覆盖该域名时用 443 与 `https`，否则用 80 与 `http`；泛域名用其下的固定名称 `edgeweir-check.<域名>`。

### 解析状态

控制台在请求时用所在主机的系统 DNS 解析器（每次 3 秒超时，最多 2 次）查询每个域名的 A 与 AAAA 记录，与集群活动节点的地址（配置的调度地址或上报的公网地址，含备用地址与离线节点）比较：

| 状态 | 含义 | 计入「DNS 已指向」 |
| --- | --- | --- |
| 「指向正确」 | 解析到的全部地址都属于集群的活动节点 | 是（已指向） |
| 「指向其他地址」 | 至少一个地址不属于集群的活动节点（例如仍指向源站或旧 CDN） | 是（未指向） |
| 「未解析」 | 没有 A 或 AAAA 记录（含域名不存在） | 是（未指向） |
| 「未能检查」 | 解析失败（超时等），或集群节点没有已知地址 | 是（未指向，不列为失败） |
| 「无法检查」 | `.` 后缀或正则域名：不对应单个主机名 | 否 |

- 泛域名 `*.example.com` 解析其下的固定名称 `edgeweir-check.example.com`。
- 通过 CNAME 接入时，CNAME 链最终解析到的地址同样须属于集群节点。
- 解析器缓存的结果（含「不存在」）在其 TTL 内仍然有效：修改 DNS 后「重新检查」可能仍显示旧结果。
- 解析状态只用于提示，不影响节点是否服务该域名。

## 域名写法

| 写法 | 例子 | 匹配 | 不匹配 |
| --- | --- | --- | --- |
| 精确 | `shop.example.com` | `shop.example.com` | `www.shop.example.com` |
| `*.` | `*.example.com` | `img.example.com` | `a.img.example.com`、`example.com` |
| `.` | `.example.com` | `img.example.com`、`a.img.example.com` | `example.com` |
| `~正则` | `~(www\|m)\.example\.com` | `www.example.com`、`m.example.com` | `wwwx.example.com`、`www.example.com.evil` |

- 在网站「域名」页签（见[编辑域名](#编辑域名)）或「新建网站」对话框中填写；新建网站时每行一个，或以空格、逗号分隔（正则中的逗号不分隔）。
- 主机名不区分大小写，保存为小写；结尾的 `.` 与端口、粘贴的 URL 的协议与路径会去掉。
- 每个网站 1–50 个域名，其中正则域名最多 10 条。同一写法的同一名称只能属于一个网站（`*.a.com` 与 `.a.com` 是不同写法，可以属于不同网站）；被占用时提示「域名已被使用：…」（`DOMAIN_IN_USE`）。
- 列表中泛域名、后缀域名、正则域名分别带「泛域名」「全部子域名」「正则」标记。

### 国际化域名

- 可以直接输入 Unicode 域名。控制台按 UTS #46（非过渡处理：`ß`、`ς` 保留为原字符）转换为 Punycode 保存，例如 `bücher.example` 保存为 `xn--bcher-kva.example`；也可以直接输入 Punycode。
- 列表与网站列表显示 Unicode，鼠标悬停显示 Punycode。只有一种文字（或拉丁字母与汉字、假名、注音、谚文的组合）的标签显示为 Unicode；混用文字的标签（例如拉丁字母中混入西里尔字母的仿冒名称）保持 Punycode。
- 网站搜索用两种形式都能找到，也能按 Unicode 名称的一部分搜索（`büch`）。
- UTS #46 不允许的名称（例如违反双向文字规则、含不允许的字符，或解码后以 `-` 开头或结尾的标签）保存时提示「域名无效：…」（`DOMAIN_INVALID`）。
- 浏览器发出的 Host 是 Punycode：正则域名对 Punycode 形式匹配。

### 正则域名

| 项目 | 规则 |
| --- | --- |
| 匹配 | 对小写 Host 整串匹配，等同 `^(?:正则)$`，不需要写 `^` 与 `$` |
| 语法 | 与[规则表达式的 `matches`](rules.md) 相同的子集：可打印 ASCII，最长 256 字符；`.` 匹配任意一个字符 |
| 字母 | 只能是小写（转义序列如 `\d`、`\W`、`\x2A` 除外）：Host 已转小写 |
| 重复 | 最多两个可重复的量词：`*`、`+`、`{n,}` 与上限大于 1 的 `{n,m}`（固定次数的 `{n}` 不算） |
| 分支 | 每组（与整个正则）的选项数、每个可选部分（`?`、`{0,1}`，各算 2）相乘最多 16，例如 `(a\|b)(c\|d)e?` 为 2 × 2 × 2 = 8（分组不带量词） |
| 不允许 | `"`、`\\`、空白，`{n,m}` 之外的逗号（Host 中没有逗号） |

### 优先级

一个 Host 只交给一个网站，按以下顺序查找，命中即停：

1. 精确域名。
2. `*.` 泛域名（Host 去掉最左一段后的名称）。
3. `.` 后缀域名：从 Host 去掉最左一段开始，每次再去掉一段，越长的后缀越先匹配。
4. 正则域名：按网站创建时间，同一网站内按域名的保存顺序，第一个匹配的正则。

例：网站 A 有 `.example.com`，网站 B 有 `.img.example.com`，网站 C 有 `*.example.com`。`x.example.com` 交给 C（`*.` 优先于 `.`），`a.img.example.com` 交给 B（更长的后缀），`a.b.example.com` 交给 A。

Host 为 IP 地址或为空（节点 IP 访问）时只匹配精确域名；超过 253 个字符的 Host 不匹配正则域名。

刷新按 Host 找网站时与节点一致：在每个集群的已启用网站中按同样的优先级查找，几个集群都服务这个 Host 时各自刷新。预热与站点地图预热只交给一个集群：在全部集群的网站（含已停用的）中按同样的优先级选出一个网站（例如一个集群的精确域名优先于另一个集群的后缀或正则域名），由它所在集群的节点向该集群中服务这个 Host 的网站回源。只有停用网站的域名匹配时（预热只看这个集群）提示网站已停用。

### 后缀与正则域名的限制

| 项目 | 行为 |
| --- | --- |
| 上线检查 | 「域名」页签与「上线检查」显示「无法检查」，不计入「DNS 已指向 N/M」 |
| 证书 | 不计入「证书已覆盖全部域名」。一键 HTTPS 为 `.a.com` 申请 `*.a.com`（只能 DNS-01，覆盖一级）；正则域名不申请，只有正则域名的网站提示「网站只有正则域名，没有可签发的名称」 |
| HTTP-01 | 只为精确域名应答；不能用 HTTP-01 为后缀或正则匹配的主机签发 |
| HTTPS | 只对证书覆盖的主机名完成握手（证书中的同名或上一级 `*.`），其余主机名中止握手 |
| 批量重定向 | 来源的主机须为精确域名或 `*.` 下一级的主机；只被后缀或正则匹配的主机提示 `BULK_REDIRECT_HOST_UNKNOWN` |
| HTTPS 跳转 | 「不跳转的域名」只列出精确与 `*.` 域名；强制 HTTPS 不把证书不覆盖的后缀或正则主机名跳转到 HTTPS（跳过去会握手失败） |
| 端口 | 网站没有绑定请求到达的端口时按未知域名处理。集群有后缀或正则域名或默认网站时，这类请求的服务器级设置（HTTP/2、压缩、密码套件）来自默认网站（未知域名交给它且它在这个端口上时）或节点的默认设置；否则可能来自这个端口上 `*.` 域名匹配该 Host 的其他网站 |
| 刷新路径 | 只填路径时，只展开到精确域名的 URL |

## 未知域名与节点 IP 访问

1. 打开 **集群与节点**，选择集群，切换到「设置」页签。
2. 在「未知域名」卡片中，为「未绑定的域名」与「节点 IP 或空 Host」分别选择处理方式。
3. 选了「交给默认网站」时，在「默认网站」中选择本集群一个已启用网站；需要时打开「未知 SNI 使用默认网站的证书」。
4. 点击「保存」。控制台发布集群的配置版本（原因「修改未知域名设置」）。

| 处理方式 | HTTP | HTTPS |
| --- | --- | --- |
| 未知域名页（404，默认） | 平台的「未知域名」错误页，`X-Edgeweir-Error: unknown-host` | 未知 SNI 中止握手；没有 SNI 的连接用节点的健康证书握手，Host 为 IP 或空时返回 421 |
| 关闭连接（444） | 不返回任何内容，直接关闭连接（`curl` 显示 `Empty reply from server`） | 同左（握手照常按 SNI 处理） |
| 交给默认网站 | 按默认网站的设置处理请求（源站、缓存、规则），Host 不变 | 未知 SNI 默认中止握手，打开「未知 SNI 使用默认网站的证书」后用默认网站的证书握手；没有 SNI 的连接用健康证书握手后交给默认网站 |

- 停用网站的域名仍返回停用页面（503），不交给默认网站；同一 Host 也被已启用网站的 `*.`、后缀或正则域名匹配时，由那个网站服务。
- 没有 Host 的请求（HTTP/1.0）属于节点 IP 访问，即使默认网站接管了监听的默认 server。
- 默认网站停用后，交给它的请求暂按「未知域名页」处理，卡片提示「默认网站已停用，暂用未知域名页」；删除默认网站时设置中的默认网站被清空。
- 默认网站没有绑定请求到达的端口（[网站端口](https.md#网站端口)）时按「未知域名页」处理。
- 默认网站须为本集群已启用的网站（`DEFAULT_SITE_INVALID`）；打开「未知 SNI 使用默认网站的证书」需要默认网站有证书（`DEFAULT_SITE_CERTIFICATE_REQUIRED`）。
- 「交给默认网站」时，节点用默认网站的 HTTP/2、压缩与密码套件设置应答交给它的请求（没有 Host 的请求用节点的默认设置）。
- 交给默认网站的请求保留原 Host，缓存键总是包含 Host（网站的缓存键不含 Host 时也一样）：任意 Host 都写不进默认网站访客读取的缓存。
- 默认网站打开强制 HTTPS 时：没有证书则交给它的请求返回 503；只有打开「未知 SNI 使用默认网站的证书」且证书覆盖该主机名时才跳转到 HTTPS，否则照常以 HTTP 应答。
- 「默认网站」可以按名称或域名搜索。

### 扫描防护

| 字段 | 取值 | 默认值 | 作用 |
| --- | --- | --- | --- |
| 扫描防护 | 开 / 关 | 关 | 统计每个访客对未知域名与节点 IP 的请求 |
| 60 秒内请求超过 | 10–10000 | 100 | 第一次请求起 60 秒内超过这个数，下一次请求触发封禁 |
| 封禁秒数 | 60–86400 | 3600 | 封禁时长 |

- 不论处理方式（含交给默认网站）都计数；按访客 IP 计（IPv4 按地址，IPv6 按 /64），访客 IP 的来源见[访客 IP](../deploy/nodes.md#访客-ip)。
- 节点前有负载均衡或代理时，先把「访客 IP」设为「PROXY protocol」，或设为「可信代理报头」并把代理的地址填进「可信 CIDR」；否则计数与封禁的是负载均衡器的地址，经它访问的访客全部被拒绝。
- 触发后以「全局」范围（API 中为 `platform`）封禁该访客：节点的全部网站返回 403（`X-Edgeweir-Error: ip-banned`）。封禁出现在 **IP 名单与封禁 → 封禁** 中，原因为「扫描未知域名」，触发条件为「未知域名请求」；按「共享自动封禁」设置分发到其他节点，见[封禁](bans.md)。
- 放行名单（平台 IP 名单的放行项）与本集群的可信代理不计数；回环地址不封禁；节点的内核封禁不丢弃本集群的可信代理。
- 覆盖其他集群可信代理的封禁只在触发它的节点上生效，不分发到其他节点。
- 解封后访客继续扫描会再次被封禁。
- TLS 握手阶段中止的连接（未知 SNI）不计数。

## CNAME 前缀

集群开启 [DNS 调度](dns.md) 后，网站与 L4 应用的 CNAME 目标为 `<CNAME 前缀>.<集群域名>`。

| 对象 | 前缀 |
| --- | --- |
| 新建的网站与 L4 应用 | 随机 8 位：小写字母开头，其余为小写字母或数字 |
| 升级前已有的网站与 L4 应用 | 原来的 UUID，CNAME 目标不变 |

### 重新生成与自定义

1. 打开网站「域名」页签的「CNAME 目标」卡片，或 L4 应用页的「CNAME 目标」。
2. 点击「重新生成」并确认（「重新生成 CNAME 前缀？」，「旧名称继续解析 24 小时」），得到新的随机前缀；或点击「自定义」，在「CNAME 前缀」中填写后点击「保存」。
3. 控制台提示「CNAME 前缀已修改」。自动模式下立即发布集群的 DNS 版本（原因「修改 … 的 CNAME 前缀」）；手动模式下控制台不写记录，在 DNS 页签列出的记录中创建新名称。
4. 把各域名的 CNAME 记录改为新的目标。旧名称在卡片中划线显示，并注明「解析至 …」。

| 规则 | 说明 |
| --- | --- |
| 格式 | 1–30 位小写字母、数字或 `-`，不以 `-` 开头或结尾（输入的大写字母转小写） |
| 唯一 | 在全部网站与 L4 应用中唯一；其他对象仍在过渡期的旧前缀同样占用 |
| 保留 | `all`、`all-<数字>`，以及任一集群 DNS 绑定的汇总记录名与线路名 |
| 冲突 | 返回 `CNAME_PREFIX_CONFLICT`（「CNAME 前缀 … 已被使用或保留」）；格式不符时输入框下提示「1–30 位小写字母、数字或 -，不以 - 开头或结尾」，API 返回 400 校验错误；UUID 只接受对象自己升级前的 UUID 前缀（当前前缀或过渡期内的旧前缀），其他 UUID 返回 `CNAME_PREFIX_INVALID`（「CNAME 前缀 … 无效」） |
| 区域中已有的记录 | 自动模式下，`<前缀>.<集群域名>`（打开「保留网站线路别名」时含 `<线路名称>.<前缀>.<集群域名>`）在 DNS 服务商区域中已有非本集群管理的记录时，自定义前缀同样返回 `CNAME_PREFIX_CONFLICT`；区域读取失败或 15 秒内无响应时不检查 |
| 过渡期 | 旧前缀继续解析 24 小时：DNS 计划同时保留新旧两条 CNAME（打开「保留网站线路别名」时也保留旧名称的线路别名）；到期后每分钟的 DNS 任务删除旧名称，自动模式下发布 DNS 版本（原因「旧 CNAME 前缀到期」），手动模式下由你删除旧记录 |
| 未发布的名称 | 自动模式下从未写入 DNS 服务商的前缀（例如保存时未能读取区域，之后同步因区域中已有的记录失败）被替换时不保留，立即离开计划 |
| 取回 | 原对象可以在过渡期内取回旧前缀：点击旧名称旁的「恢复」，或在「自定义」中填写；升级前的 UUID 前缀也能用「恢复」取回 |
| 审计 | `site.cname_update`、`l4.cname_update`（`from`、`to`） |

DNS 绑定的线路名与任一前缀（含过渡期内的旧前缀）相同时，保存绑定返回 `DNS_BINDING_CONFLICT`。

## 节点要求

| 能力 | 需要它的设置 |
| --- | --- |
| `domains-v2` | 网站（含停用网站）有后缀或正则域名 |
| `unknown-host-v1` | 未知域名设置不是默认值（任一处理方式不是「未知域名页」，或打开扫描防护） |

集群有活动节点缺少 `domains-v2` 时，「域名」页签与「新建网站」对话框提示「集群中有节点不支持后缀与正则域名」；缺少 `unknown-host-v1` 时「未知域名」卡片提示「集群中有节点不支持」。服务账号与后台任务发布时返回 `NODE_CAPABILITY_REQUIRED`。升级节点见[节点升级](node-upgrades.md)。

| 变更 | 生效方式 |
| --- | --- |
| 域名、默认网站之外的未知域名设置、扫描防护 | 热更新 |
| 正则域名的每次增删（含停用网站的）、第一条后缀域名的增删、有 TLS 设置的网站的域名、「交给默认网站」的开关与默认网站 | 重载 nginx（`server_name`、`default_server` 或正则缓存的大小变化），已有连接不中断 |

## API

| 操作 | 方法与路径 |
| --- | --- |
| 修改网站的域名 | `PATCH /api/v1/sites/{id}`（`{"domains": ["a.com", "*.a.com"]}`，整体替换） |
| 读取 CNAME 目标 | `GET /api/v1/sites/{siteId}/cname`（`target`、`mode`、`published`、`healthy`、`lines`、`retired`；没有 DNS 绑定时 `target` 为 `null`） |
| 上线检查（边缘地址、解析状态、证书覆盖） | `GET /api/v1/sites/{id}/launch` |
| 节点是否支持后缀与正则域名 | `GET /api/v1/sites/{id}/features`（`domainsV2`） |
| 读取未知域名设置 | `GET /api/v1/clusters/{clusterId}/unknown-hosts` |
| 保存未知域名设置 | `PUT /api/v1/clusters/{clusterId}/unknown-hosts` |
| 修改网站的 CNAME 前缀 | `PUT /api/v1/sites/{id}/cname-prefix`（`{"prefix": "shop"}`；省略 `prefix` 为重新生成） |
| 修改 L4 应用的 CNAME 前缀 | `PUT /api/v1/l4-apps/{id}/cname-prefix` |

字段见 [API 参考](../reference/api/sites.md#网站)。只读 AccessKey 只能调用 `GET`。服务账号只能调用 `GET /sites/{siteId}/cname` 与 `GET /sites/{id}/launch`（`sites:read`）。

## 故障排查

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| 保存域名提示「域名无效：…」（`DOMAIN_INVALID`） | Unicode 名称不符合 UTS #46，或正则含大写字母、`"`、空白、逗号，超过两个可重复的量词，分支相乘超过 16，或超出语法子集 | 改正名称；正则中的字母改为小写；把几个域名分开写；减少 `*`、`+` 等量词与 `\|`、`?` 分支，或改用后缀域名 |
| 强制 HTTPS 没有跳转某个后缀或正则主机名 | 网站证书不覆盖这个主机名 | 使用覆盖它的证书 |
| `x.a.com` 交给了别的网站 | 另一个网站有 `x.a.com`、`*.a.com` 或更长的后缀 | 按[优先级](#优先级)检查各网站的域名 |
| 后缀域名下的 HTTPS 握手失败 | 证书只覆盖一级（`*.a.com`），多级子域名不在证书中 | 为需要 HTTPS 的多级主机名使用覆盖它们的证书，或改用精确域名 |
| 访问未绑定的域名没有任何响应 | 「未绑定的域名」为「关闭连接（444）」 | 改为「未知域名页（404）」 |
| 访客突然收到 403 `ip-banned` | 扫描防护封禁了该地址 | 在 **IP 名单与封禁 → 封禁** 中解除，或把地址加入平台放行名单 |
| 修改 CNAME 前缀后旧名称不再解析 | 已过 24 小时过渡期 | 把域名的 CNAME 记录改为新目标 |
| 保存域名提示「域名已被使用：…」（`DOMAIN_IN_USE`） | 同一写法的同一名称已属于另一个网站 | 从那个网站移除该域名，或改用其他写法（`*.a.com` 与 `.a.com` 可以分属不同网站） |
| 保存域名提示「证书域名与网站或 DNS 区域不匹配：…」（`CERTIFICATE_DOMAIN_MISMATCH`） | 网站的证书不覆盖新域名，且不能自动扩展（上传的证书、关闭自动续期、HTTP-01 证书遇到泛域名、DNS-01 证书遇到区域外的名称，或超过 100 个名称） | 先上传或申请覆盖新域名的证书，见[为 HTTPS 网站添加域名](https.md#为-https-网站添加域名) |
| 保存后缀或正则域名提示「集群中有节点不支持后缀与正则域名」 | 集群有活动节点缺少 `domains-v2` | 升级节点，见[节点升级](node-upgrades.md) |
| 域名显示「指向其他地址」 | 域名仍解析到源站、旧 CDN 或集群以外的地址 | 把 A / AAAA 记录改为「边缘地址」，或把 CNAME 指向「CNAME 目标」 |
| 域名显示「未解析」 | 域名没有 A 或 AAAA 记录 | 添加记录；刚添加时等解析器缓存过期后点击「重新检查」 |
| 域名显示「未能检查」 | 控制台所在主机的 DNS 解析超时或失败，或集群节点没有已知地址 | 检查控制台主机的 DNS 解析；确认节点在线并上报了公网地址，或为节点配置调度地址 |
| 「CNAME 目标」长时间为「待发布」 | DNS 版本未能应用到服务商，或被大面积摘除保护暂缓 | 在 **集群与节点** 的 **DNS** 页签查看 DNS 版本，见 [DNS 版本与回滚](dns.md#dns-版本与回滚) |
| 「CNAME 目标」为「无健康节点」 | 集群的节点都被健康摘除 | 检查节点状态，见[健康摘除与修复](dns.md#健康摘除与修复) |
| 「边缘地址」为「无公网地址」 | 在线节点没有上报公网地址，也没有配置调度地址 | 为节点配置调度地址，见[调度地址与备用 IP](scheduling.md#调度地址与备用-ip) |
| 保存未知域名设置提示「默认网站须为本集群已启用的网站」（`DEFAULT_SITE_INVALID`） | 默认网站不在本集群或已停用 | 选择本集群一个已启用的网站 |
| 保存未知域名设置提示「默认网站没有证书」（`DEFAULT_SITE_CERTIFICATE_REQUIRED`） | 打开了「未知 SNI 使用默认网站的证书」，默认网站没有证书 | 先为默认网站配置证书，或关闭该开关 |
