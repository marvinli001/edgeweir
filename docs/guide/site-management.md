# 网站管理

网站列表、新建网站、网站页面与概览页签、星标、标签、批量操作、复制设置、克隆与删除网站。

## 概念

| 术语 | 定义 |
| --- | --- |
| 网站 | 一组域名、源站与设置，属于一个集群。网站的每次保存由所在集群发布新的配置版本下发到节点，见[配置版本](clusters.md#配置版本)。 |
| 网站页签 | 网站页面（`/sites/<网站 ID>`）的分区，地址为 `?tab=<页签>`，见[网站页签](#网站页签)。 |
| 星标 | 账号对网站的标记。星标网站排在概览「网站」卡片与命令面板的前面。不下发到节点，不产生配置版本。 |
| 标签 | 网站的分组名称，1–32 个字符，不区分大小写（`Prod` 与 `prod` 是同一个标签，显示第一次写下的写法）。每个网站最多 10 个。标签只在控制台使用，不下发到节点，修改标签不产生配置版本。 |
| 批量操作 | 在网站列表选中若干网站后执行的启用、停用、刷新缓存、添加标签、移除标签、复制设置与删除，一次最多 100 个网站。 |
| 复制设置 | 把源网站选中部分的设置写到目标网站，替换目标的这些设置。一次性操作：之后修改源网站不影响目标网站。 |
| 部分 | 复制设置的单位，见[可以复制的部分](#可以复制的部分)。 |
| 克隆 | 以源网站的全部设置和源站新建一个网站，填写新的名称与域名。一次性操作。 |

## 网站列表

页面：**网站**（`/sites`）。筛选栏左侧的「网站 | L4 应用」切换网站列表与 [L4 应用](l4.md)（`/l4`）。

| 控件 | 说明 |
| --- | --- |
| 搜索框 | 占位「搜索名称、域名或标签」，最多 100 字符，停止输入 300 毫秒后搜索。匹配网站名称、任一域名（含 `*.`、`.`、`~` 写法前缀；国际化域名按 Unicode 与 Punycode 两种形式，见[国际化域名](domains.md#国际化域名)）或任一标签名，不区分大小写 |
| 「集群」 | 有多个集群时显示；「全部集群」或单个集群 |
| 「标签」 | 有标签时显示，见[标签](#标签) |
| 「管理标签」 | 有标签时显示，见[标签](#标签) |
| 「新建网站」 | 页面右上角，见[新建网站](#新建网站) |

| 列 | 内容 |
| --- | --- |
| 「网站」 | 选择框、星标按钮、网站名称（链接到网站页面，悬停显示「创建于 …」）与标签。点击标签只看带该标签的网站 |
| 「状态」 | 「运行中」「已停用」「待接入」「生效中 N/M」或金丝雀状态，见[网站启停](clusters.md#网站启停)；[用量保护](usage-protection.md)执行动作期间另有「用量超限」 |
| 「24 小时请求」 | 过去 24 小时的请求趋势与总数，每 60 秒刷新。只在没有搜索与筛选、位于第 1 页且网站总数不超过 20 时显示 |
| 「域名」 | 第一个域名，其余收在「+N」中（悬停列出） |
| 「源站」 | 第一个源站 `协议://地址:端口`，其余收在「+N」中；窄屏不显示 |
| 「集群」 | 有多个集群时显示 |

- 网站按创建时间排序（最早的在前），每页 20 个，表头不提供排序。
- 有网站未全部生效时列表每 5 秒刷新一次。
- 没有网站时显示「暂无网站」与「新建网站」；搜索或筛选无结果时显示「没有匹配的网站」与「清除筛选」。
- 搜索、筛选与页码保存在地址中（`q`、`cluster`、`tags`、`match`、`page`）；`/sites?create=true` 打开「新建网站」对话框。

## 新建网站

1. 在 **网站** 点击「新建网站」（或在命令面板中选择「新建网站」）。
2. 填写表单，点击「创建」。
3. 所在集群发布新的配置版本（原因「新建网站 {site}」），页面进入网站的「概览」页签；提示「网站已创建」随节点更新到「已生效」，见[网站启停](clusters.md#网站启停)。

| 字段 | 取值与限制 | 默认值 | 说明 |
| --- | --- | --- | --- |
| 「名称」 | 1–100 字符 | 第一个域名（超过 100 字符时截断） | 网站的显示名称，可在「概览」页签修改 |
| 「集群」 | 本控制台的集群 | 列表按集群筛选时为该集群，否则为最早创建的集群 | 只在有多个集群时显示。创建后不能更换 |
| 「域名」 | 1–50 个，其中正则域名最多 10 个 | 无 | 每行一个，或以空格、逗号分隔（正则中的逗号不分隔）；写法见[域名写法](domains.md#域名写法)。同一写法的同一名称只能属于一个网站 |
| 「源站地址」 | IP 或主机名 | 无 | 粘贴 URL（`https://origin.example.com:8443/app`）或 `主机:端口` 时，端口与协议填入各自的字段 |
| 「端口」 | 1–65535 | 80（HTTP）/ 443（HTTPS） | 源站端口 |
| 「回源协议」 | HTTP、HTTPS | HTTP | 节点连接源站的协议 |
| 「回源 Host」 | 主机名或 IP，可带端口（IPv6 带端口时加方括号），最多 259 字符 | 空（「跟随请求」） | 发往源站的 `Host`；格式不符时提示「填写域名或 IP，可带端口；IPv6 带端口时加方括号」 |
| 「缓存」 | 开 / 关 | 开 | 开启时创建一条缓存规则；关闭时网站没有缓存规则 |
| 「路径前缀」 | 以 `/` 开头，最多 1024 字符，不含空白 | `/` | 缓存规则匹配的路径前缀 |
| 「缓存时间（秒）」 | 0–31536000 | 3600 | 缓存规则的边缘缓存时间 |
| 「遵循源站 Cache-Control」 | 开 / 关 | 开 | 开启时按源站的 `Cache-Control` 缓存，关闭时以「缓存时间（秒）」覆盖，见[配置缓存规则](origins-and-cache.md#配置缓存规则) |

- 新网站的端口为 80 与 443，CNAME 前缀为随机 8 位（见 [CNAME 前缀](domains.md#cname-前缀)），没有证书（见 [HTTPS 与证书](https.md)）。
- 后缀域名 `.a.com` 与正则域名需要集群的全部活动节点支持 `domains-v2`，否则提示「集群中有节点不支持后缀与正则域名」。
- 经 API 创建时可同时设置源站池、缓存设置、内容设置、端口与标签（`tags`，最多 10 个），见 [API 参考](../reference/api/sites.md#网站)。
- 完整的上线流程（节点、DNS、HTTPS、验证）见[快速上手](first-site.md#3-新建网站)。

### 上线检查

「上线检查」卡片每 30 秒检查一次，右上角的「重新检查」立即检查。每行链接到处理它的页面。

| 行 | 状态 | 链接 |
| --- | --- | --- |
| DNS | 「DNS 已指向 {ok}/{total}」：可检查的域名中解析到集群节点的数量，右侧列出未解析或指向其他地址的域名；只有后缀与正则域名时为「无法检查」。判定规则见[解析状态](domains.md#解析状态) | 「域名」页签 |
| 证书 | 「未配置证书」「证书已覆盖全部域名」「证书未覆盖全部域名」（右侧列出未覆盖的域名）「证书签发中」「证书签发失败」（右侧为失败原因）「证书已过期」。后缀与正则域名不计入 | 「HTTPS」页签 |
| 节点 | 「已在 {current}/{total} 个节点生效」；网站停用时为「已停用」，集群没有在线节点时为「没有在线节点」；金丝雀期间右侧为「金丝雀中，{time} 全部生效」或「金丝雀中，待推进」 | **集群与节点** |

## 星标

- 点击网站列表「网站」列或网站页面标题栏的星形按钮（「加星标」/「取消星标」）。
- 星标按账号保存。概览「网站」卡片先列出星标网站（最近加星的在前），再列出其他网站；命令面板（⌘K / Ctrl+K）未输入时先列出星标网站，再列出最近打开的网站。

## 标签

- **添加或修改**：打开 **网站 →（网站）→ 概览**，点击「标签」一行的编辑按钮，输入名称后按回车（或逗号；粘贴以逗号分隔的列表一次加入多个），点击「保存」，提示「标签已保存」。输入时提示已有的标签；已有标签沿用其写法。名称超过 32 个字符时提示「标签为 1–32 个字符」，超过 10 个时提示「最多 10 个标签」。新建网站（API）与克隆网站时也可以填写标签。
- **筛选**：在 **网站** 列表点击筛选栏的「标签」，勾选一个或多个标签（最多 10 个，每项右侧为网站数），选择「含任一标签」或「含全部标签」。点击网站名旁的标签只看带这个标签的网站。搜索框也按标签名搜索。
- **在命令面板中**：按 ⌘K（Windows / Linux 为 Ctrl+K）输入标签名，选择「标签：…」打开按该标签筛选的列表。
- **改名与删除**：点击筛选栏的「管理标签」。改名为另一个已有标签的名称（不区分大小写）时，两个标签合并为一个。删除标签前确认「删除标签「{name}」？」（「将从 N 个网站上移除」），删除后从所有网站上移除。没有网站使用的标签保留在这里，直到删除。
- 修改标签写审计「修改网站标签」（每个变化的网站一条）、「重命名标签」「删除标签」；不发布配置版本。

## 批量操作

1. 在 **网站** 列表勾选网站（表头的选择框选择本页全部）。换页后选择仍然保留；改变搜索或筛选条件会清空选择。最多选择 100 个，达到时操作栏显示「最多 100 个」。
2. 在页面底部的操作栏（「已选 N 个」）选择操作：「启用」「停用」「刷新缓存」直接在操作栏中，「添加标签」「移除标签」「复制设置」「删除」在「更多」中。「取消选择」清空选择。

| 操作 | 确认 | 效果 |
| --- | --- | --- |
| 启用 / 停用 | 「启用 N 个网站？」/「停用 N 个网站？」，列出所选网站 | 已经是该状态的网站不变。每个改变了状态的网站写一条审计记录（与单个网站的启用、停用相同）；每个集群只发布一个新的配置版本，原因「启用 N 个网站」「停用 N 个网站」（集群里只有一个网站变化时为该网站的原因）。提示「已启用 N 个网站」「已停用 N 个网站」，N 为实际改变的网站数 |
| 刷新缓存 | 「刷新 N 个网站的全部缓存？」 | 为所选网站创建一个全站刷新任务，在 **刷新预热** 查看各节点的结果。所选网站中有已停用的网站时整个操作失败（「网站已停用」） |
| 添加标签 / 移除标签 | 「给 N 个网站添加标签」/「从 N 个网站移除标签」，填写标签 | 给所选网站加上或去掉若干标签（每次最多 10 个名称）。任一网站加上后超过 10 个标签时整个操作失败（「网站 {site} 最多 10 个标签」）。不发布配置版本 |
| 复制设置 | 选择源网站与部分 | 见[复制设置](#复制设置) |
| 删除 | 「删除 N 个网站？」，在「输入 N 确认删除」中输入所选网站的数量 | 每个网站写一条审计记录，每个集群只发布一次（原因「删除 N 个网站」）。其余同[删除网站](#删除网站) |

启用、停用、标签与删除要么全部完成，要么一个都不改（例如所选网站中有一个已被删除，`SITE_NOT_FOUND`）。

## 复制设置

1. 在网站页面标题栏的「⋯」中点击「复制设置」，选择「目标网站」；或在网站列表选中目标网站，在操作栏的「更多」中点击「复制设置」，选择「源网站」。
2. 在「复制哪些设置」中勾选要复制的部分（「全选」/「全不选」），点击「预览」。
3. 预览列出每个目标网站各部分的变化（列表类的部分显示「{before} → {after} 项」，其他部分显示「N 项设置变化」，没有变化时为「无变化」），以及会失败的网站和原因。预览不保存任何内容。
4. 点击「复制到 N 个网站」。提示「已复制到 N 个网站，M 个失败」；结果列出每个网站复制了哪些部分，或失败的原因。

- 目标网站 1–100 个，不能包含源网站。
- 每个目标网站单独保存：一个网站失败时，它的设置保持不变，其他网站照常复制。
- 每个复制成功的网站发布所在集群的新配置版本（原因「把 {source} 的设置复制到 {site}」，内容没有变化时不产生新版本），并写审计记录「复制网站设置」，记录源网站、复制的部分和实际变化的部分。
- 复制的部分会整体替换目标网站的该部分，例如目标原有的网站规则全部被源网站的规则取代。

### 可以复制的部分

| 部分 | 复制的内容 | 不复制 |
| --- | --- | --- |
| 缓存规则 | 全部缓存规则 | |

| 网站规则 | 网站的全部规则（各阶段）与规则读取请求体的上限 | |
| 批量重定向 | 整个重定向表 | |
| 错误页 | 各状态的错误页与「替换源站错误响应」 | 维护模式 |
| OWASP CRS | 模式、偏执级别、异常阈值、请求体检查上限与排除项 | |

### 复制失败的原因

目标网站缺少设置里用到的对象时，该网站复制失败：

| 提示 | 错误码 | 说明 |
| --- | --- | --- |
| 规则「…」选择的源站组 … 在该网站不存在 | `ORIGIN_GROUP_UNKNOWN` | 先在目标网站的「源站」页签添加同名的源站组 |
| HTTPS 跳转、HSTS 和客户端证书需要网站有证书 | `HTTPS_REQUIRES_CERTIFICATE` | 目标网站没有证书；先为它配置证书，或不复制「HTTPS 选项」 |
| 网站没有这些域名：… / 网站没有域名 … | `BULK_REDIRECT_HOST_UNKNOWN` / `AUTH_DOMAIN_UNKNOWN` | 批量重定向的来源（`域名/路径`）或访问鉴权规则的域名范围写着目标网站没有的域名 |
| 跳转端口 … 不是网站的 HTTPS 端口 | `HTTPS_REDIRECT_PORT_INVALID` | 先给目标网站加上该端口，或在源网站改用 443 |
| IP 名单不存在 | `IP_LIST_NOT_FOUND` | 设置引用的 IP 名单在复制时被删除了 |

## 克隆网站

1. 在网站页面标题栏的「⋯」中点击「克隆」，打开「克隆 {name}」（提示「证书不会复制」）。
2. 填写「名称」（留空为第一个域名）和「域名」（必填，规则同[新建网站](#新建网站)），按需修改「标签」（默认为源网站的标签），点击「克隆」。
3. 提示「网站已克隆」，页面进入新网站。

| 项目 | 新网站 |
| --- | --- |
| 集群 | 与源网站相同 |
| 复制自源网站 | 源站（S3 凭据为新网站重新加密）、全部[可以复制的部分](#可以复制的部分)、X-Cache、PURGE 方法与密钥（重新加密）、字符编码、请求体上限与维护模式 |
| 证书 | 不复制（证书只覆盖源网站的域名）；强制 HTTPS、HSTS、客户端证书为关闭，不跳转的域名为空 |
| 端口 | HTTP 端口同源网站（源网站没有 HTTP 端口时为 80）；HTTPS 端口在源网站有 443 时为 443，否则没有 |
| CNAME 前缀 | 新的随机前缀 |
| 版本与审计 | 发布所在集群的新配置版本（原因「从 {source} 克隆网站 {site}」），写审计「克隆网站」 |

源网站的访问鉴权域名范围或批量重定向来源写着新网站没有的域名（例如源网站的域名），或设置引用的 IP 名单不存在时，克隆失败并提示原因（`AUTH_DOMAIN_UNKNOWN`、`BULK_REDIRECT_HOST_UNKNOWN`、`IP_LIST_NOT_FOUND`），不创建网站。

## 删除网站

1. 在网站页面标题栏的「⋯」中点击「删除」。
2. 确认「删除 {name}？」。提示「已删除，版本 #N」，页面回到网站列表。

- 所在集群发布新的配置版本（原因「删除网站 {site}」），写审计「删除网站」；节点不再服务该网站的域名。
- 网站的统计、存于 PostgreSQL 的访问日志、网站范围的封禁与用量保护随网站删除；只订阅了该网站的告警订阅一并删除。
- 网站是集群[默认网站](domains.md#未知域名与节点-ip-访问)时，设置中的默认网站被清空。
- 证书不随网站删除，在 **证书** 页面管理。
- 删除不能撤销。批量删除见[批量操作](#批量操作)。

## 接口

| 操作 | 接口 |
| --- | --- |
| 列出网站（搜索、集群、标签、分页） | `GET /api/v1/sites?search=&clusterId=&tagIds[]=<id>&tagMatch=all&page=&pageSize=`（`pageSize` 1–100，默认 20） |
| 读取网站 | `GET /api/v1/sites/{id}` |
| 新建网站 | `POST /api/v1/sites`（201） |
| 修改网站（名称、域名、源站、缓存等） | `PATCH /api/v1/sites/{id}` |
| 删除网站 | `DELETE /api/v1/sites/{id}` |
| 启用 / 停用 | `PUT /api/v1/sites/{id}/enabled` |
| 上线检查 | `GET /api/v1/sites/{id}/launch` |
| 全站刷新 | `POST /api/v1/sites/{id}/purge` |
| 星标列表、设置星标 | `GET /api/v1/starred-sites`、`PUT /api/v1/sites/{id}/starred`（`{"starred": true}`） |
| 设置网站标签 | `PUT /api/v1/sites/{id}/tags` |
| 标签列表、改名、删除 | `GET /api/v1/site-tags`、`PATCH /api/v1/site-tags/{id}`、`DELETE /api/v1/site-tags/{id}` |
| 批量启停、标签、删除 | `POST /api/v1/sites/batch/enabled`、`/batch/tags`、`/batch/delete` |
| 批量刷新 | `POST /api/v1/cache-tasks`（`{"type": "site", "siteIds": [...]}`） |
| 预览与复制 | `GET`、`POST /api/v1/sites/{id}/copy-settings` |
| 克隆 | `POST /api/v1/sites/{id}/clone`（201） |

字段与错误码见 [API 参考](../reference/api/sites.md#网站标签与批量操作)。只读 AccessKey 只能调用 `GET`。服务账号只能调用 `GET /sites`、`GET /sites/{id}`、`GET /sites/{id}/launch`（`sites:read`）与 `PUT /sites/{id}/enabled`（`sites:write`），见[服务账号](system.md#服务账号)。

## 故障排查

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| 保存时提示「域名已被使用：…」（`DOMAIN_IN_USE`） | 同一写法的同一名称已属于另一个网站 | 从另一个网站移除该域名，或改用其他写法，见[优先级](domains.md#优先级) |
| 新建时提示「此集群最多发布 512 个网站」（`CLUSTER_SITE_LIMIT`） | 集群已发布 512 个已启用的网站 | 停用或删除网站，或在另一个集群新建 |
| 新建时提示「填写域名或 IP，可带端口；IPv6 带端口时加方括号」 | 「回源 Host」格式不符 | 改为主机名或 IP，或留空跟随请求 |
| 源站地址提示「源站地址 … 属于特殊用途地址段 …」（`ORIGIN_ADDRESS_FORBIDDEN`） | 源站是私有、回环等特殊用途地址 | 改用公网地址，或在系统设置的源站地址允许清单中加入该地址段，见[源站地址限制](origins-and-cache.md#源站地址限制) |
| 停用或启用时提示「内容已被修改，请刷新后重试」（`UPDATED_AT_MISMATCH`） | 打开页面后网站被修改过 | 刷新页面后重试 |
| 「24 小时请求」列不显示 | 有搜索或筛选、不在第 1 页，或网站超过 20 个 | 在网站的「统计」页签查看 |
| 批量刷新提示「网站已停用」（`SITE_DISABLED`） | 所选网站中有已停用的网站 | 取消选择已停用的网站 |
| 添加标签提示「网站 {site} 最多 10 个标签」（`SITE_TAG_LIMIT`） | 该网站加上后超过 10 个标签 | 先移除该网站的部分标签，或不选该网站 |
| 复制设置后部分网站失败 | 目标网站缺少设置用到的对象 | 见[复制失败的原因](#复制失败的原因) |
| 上线检查的 DNS 一行不是全部指向 | 域名未解析或解析到集群节点以外的地址 | 见[解析状态](domains.md#解析状态) |
| 网站状态停在「待接入」 | 集群没有在线节点，或节点还没有应用含该网站的版本 | 见[网站启停](clusters.md#网站启停)与[节点](clusters.md#节点) |
