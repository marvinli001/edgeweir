# 分层缓存

分层缓存让节点（下层）在缓存未命中时先向同集群的其他节点（上层）取内容，上层未命中时才回源。同一对象只从源站取一次，其余节点从上层取。上层不可用时，下层直接回源。

## 概念

| 术语 | 定义 |
| --- | --- |
| 下层 | 收到访客请求、缓存未命中的节点。 |
| 上层 | 下层取内容的节点。上层用下层的缓存键缓存对象，未命中时回源。 |
| 区域层 | Regional 拓扑中，位于下层与上层之间的节点（每个其他区域一个）。 |
| 测量源站 | 网站默认源站组的第一个主源站（`主机:端口`）。参与的节点每分钟测量一次到它的 TCP 往返时间。 |
| 区域 | 节点所在节点组的区域；没有区域的节点自成一组。 |

## 拓扑

| 拓扑 | 上层的选择 |
| --- | --- |
| 关闭 | 不分层，所有节点直接回源。默认值。 |
| Smart | 到测量源站往返时间最短的节点是所有其他节点的上层；另一区域中最快的节点是备选上层。 |
| Generic | 每个区域内往返时间最短的节点（没有测量时取 ID 最小的）是该区域其他节点的上层；没有可用上层的区域使用最快区域的上层。 |
| Regional | 与 Smart 相同的上层；其他每个区域选出最快的节点作为区域层，区域内的节点经区域层再到上层（最多两跳）。 |
| 自定义 | 选中的节点与节点组中的节点是其他所有节点的上层，每个节点最多 3 个：同区域的优先，其次按往返时间。 |

- 已选的上层在往返时间不超过最快节点的 120% + 5 ms 时保持不变，避免随测量抖动切换。
- 控制台每分钟重新选择一次，上层变化时发布新版本（原因「N 个站点的上层节点变更」）。

## 开启

1. 打开 **系统**，在「分层缓存」卡片选择拓扑；需要时修改「上层端口」（默认 8444）。保存后，跟随全局的网站所在集群发布新版本。
2. 单个网站：打开 **网站** → 选择网站 →「缓存」页签，在「分层缓存」卡片选择「跟随全局」或其他拓扑。
3. 「上层节点」卡片列出集群中每个节点的上层、选择原因与往返时间；没有上层时显示原因。
4. 「分析」页签的「分层缓存」卡片显示上层命中率、上层请求、兜底回源与服务下层的请求数。

## 节点要求

| 要求 | 说明 |
| --- | --- |
| `tiered-cache-v1` | 节点参与分层缓存。没有此特性的节点直接回源，「上层节点」卡片计入「不支持」。 |
| `tier-upper-v1` | 节点可以作上层：节点证书可用于 TLS 服务端。旧证书的节点在一天内自动续期一次后具备。 |
| 调度地址 | 上层用第一个主调度地址（IPv4 优先）接受下层连接；没有调度地址的节点不作上层。 |
| 端口 | 下层到上层的「上层端口」（TCP）需要放行。端口不能与监听端口相同。 |
| 在线 | 10 分钟内有心跳的节点才参与；往返时间超过 10 分钟的测量不计。 |

## 行为

| 情况 | 结果 |
| --- | --- |
| 请求不会被缓存（没有缓存规则命中、被绕过、非 GET / HEAD、WebSocket、gRPC） | 不经过上层，与关闭时相同 |
| 图片格式转换的请求 | 不经过上层 |
| 下层与上层之间的连接 | 双向 TLS 1.3：双方出示节点证书，按节点 CA 与节点 ID 校验；上层只接受计划中自己的下层 |
| 上层收到的请求 | 下层已做过规则、封禁、挑战与 WAF 检查，上层不再做；访客地址经 `X-Real-IP` / `X-Forwarded-For` 传递 |
| 源站看到的连接 | 来自上层节点 |
| 上层连接失败、超时或返回 502 / 504 | 依次尝试下一个上层，全部失败时直接回源；连续 2 次失败的上层 15 秒内跳过 |
| 上层回源失败（5xx）且下层有可用的过期副本 | 按缓存规则返回过期副本 |
| 请求已经过某节点（`CDN-Loop`） | 跳过该节点，不形成环路 |
| 分片（Range）请求 | 每片经过上层，上层同样按片缓存 |
| 刷新 URL、前缀、Cache-Tag 或整站 | 每个节点各自执行；上层取两者中较晚的刷新时间与较新的缓存代，不会把已刷新的对象交给下层 |
| 访问日志 | 「分层缓存」字段记录回答的上层与其缓存状态，或「回源」 |

## 统计

| 指标 | 定义 |
| --- | --- |
| 上层命中率 | 上层回答的请求中，上层从缓存回答（HIT、STALE、UPDATING、REVALIDATED）的比例 |
| 上层请求 | 下层向上层取内容并得到回答的次数 |
| 兜底回源 | 没有上层回答、下层直接回源的次数 |
| 服务下层 | 本网站在各节点作为上层时回答下层的次数 |

同一组内多个节点之间的缓存共享（一致性哈希分片、缓存索引节点）不属于分层缓存。
