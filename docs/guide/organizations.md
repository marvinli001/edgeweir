# 组织、成员与账户安全

组织与角色、成员邀请、组织两步验证策略、账户安全设置与控制台导航。

## 组织

组织是租户资源与权限的边界。网站（含域名、源站、缓存、HTTPS、规则、日志设置）、证书、DNS 凭据与 IP 名单属于一个组织；组织成员只能访问当前组织的资源。

| 项目 | 行为 |
| --- | --- |
| 创建 | 初始化向导创建第一个组织；其余组织由平台管理员在 **后台 → 组织与用户** 创建。用户不能自行创建组织 |
| 删除 | 不支持 |
| 多组织 | 一个用户可属于多个组织。属于两个及以上组织时，侧边栏顶部显示组织切换（**切换组织**） |
| 当前组织 | 保存在会话中；每次请求重新核对成员关系，失效时回退到最早加入的组织 |
| 默认集群 | 组织的新网站落在默认集群；未设置时为最早创建的集群。默认集群由平台管理员设置，组织成员不能选择集群 |
| 域名 | 一个可注册域通过归属验证后属于一个组织，见 [验证域名归属](dns-and-alerts.md#验证域名归属) |

平台管理员的跨组织权限见 [平台管理](admin.md#平台管理员)。

## 角色

组织内角色：**所有者**（`owner`）、**管理员**（`admin`）、**成员**（`member`）。组织角色中的 **管理员** 与 [平台管理员](admin.md#平台管理员) 无关。

| 能力 | 所有者 | 管理员 | 成员 |
| --- | --- | --- | --- |
| 网站、域名归属、证书与 DNS 凭据、IP 名单、刷新预热、访问日志、告警订阅 | ✓ | ✓ | ✓ |
| 创建 AccessKey（以创建者身份调用 `/api/v1`） | ✓ | ✓ | ✓ |
| 打开 **组织成员**：查看成员与待接受的邀请 | ✓ | ✓ | — |
| 邀请、修改角色、移除 **管理员** 与 **成员** | ✓ | ✓ | — |
| 授予、修改或移除 **所有者**；查看和创建所有者邀请 | ✓ | — | — |
| **组织策略**：**要求成员启用两步验证** | ✓ | ✓ | — |

| 约束 | 说明 |
| --- | --- |
| 最后一个所有者 | 组织至少保留一个所有者；移除或降级最后一个所有者被拒绝 |
| 本人 | **组织成员** 列表中本人的角色与移除操作不可用 |
| 平台管理员 | 在所属组织中按所有者处理 |

AccessKey 的范围与吊销见 [访问日志与 AccessKey](access-logs.md)。

## 邀请与成员管理

页面：**组织成员**（`/members`）。

| 操作 | 说明 |
| --- | --- |
| **邀请成员** | 填写 **邮箱** 与 **角色**，点击 **生成邀请链接**。控制台显示 **邀请链接** `https://<控制台>/invite/<邀请 ID>`，不发送邮件 |
| **待接受的邀请** | 列出未过期的邀请；可复制链接或 **取消** |
| 角色 | 在成员行的 **角色** 下拉框中修改 |
| **移除** | 从组织中移除成员；账户保留 |

| 邀请规则 | 说明 |
| --- | --- |
| 有效期 | 7 天 |
| 替换 | 同一邮箱的新邀请取消旧的待接受邀请 |
| 凭据 | 邀请 ID 是链接中的凭据；受邀邮箱尚无账户时，持有链接者可用该邮箱创建账户并加入组织 |
| 已有账户 | 须以受邀邮箱登录后接受（**登录后接受** → **接受邀请**） |
| 新账户 | 在邀请页填写 **姓名** 与 **密码**（12–128 字符），接受时创建账户 |
| 已是成员 | 拒绝邀请该邮箱 |

平台管理员另可在 **后台 → 组织与用户** 为任意组织直接添加已有用户或生成邀请，见 [平台管理](admin.md#组织与用户)。

## 组织两步验证策略

开关：**组织成员 → 组织策略 → 要求成员启用两步验证**（所有者、管理员）；平台管理员也可在 **后台 → 组织与用户** 的组织编辑中设置。

| 项目 | 行为 |
| --- | --- |
| 生效条件 | 组织开启策略，且成员未启用两步验证（TOTP）。通行密钥不满足该要求 |
| 界面 | 成员被留在 **账户安全** 页，页面显示 **组织要求启用两步验证后才能继续使用** |
| API | 该成员对组织资源的调用（含其 AccessKey 调用 `/api/v1`）返回 `TWO_FACTOR_REQUIRED` |
| 豁免 | 平台管理员不受组织策略约束 |
| 查看 | **组织成员** 表的 **两步验证** 列显示 **已启用** / **未启用** |

## 账户安全

页面：**账户安全**（`/security`），所有用户可用。账户由初始化向导、平台管理员或邀请创建，不开放自助注册。控制台不提供找回或重置密码的入口。

### 密码

| 项目 | 说明 |
| --- | --- |
| 修改 | 填写 **当前密码**、**新密码**、**确认新密码**，点击 **修改密码** |
| 长度 | 12–128 字符 |
| 其他会话 | 修改后其他设备退出登录 |

### 两步验证（TOTP）

1. 在 **两步验证（TOTP）** 中填写 **当前密码**，点击 **启用**。
2. 用验证器扫描二维码，或手动输入 **密钥**。
3. 输入 6 位 **验证码**，点击 **验证**。
4. 保存 **备用码**（仅显示一次）。

| 项目 | 说明 |
| --- | --- |
| TOTP 参数 | 6 位，30 秒，签发方 `Edgeweir` |
| 备用码 | 10 个，格式 `xxxxx-xxxxx`，每个仅可使用一次 |
| 登录 | 密码正确后进入 **两步验证**：输入验证码，或 **使用备用码** |
| 重新生成备用码 | 停用后重新启用两步验证 |
| 停用 | 填写 **当前密码**，点击 **停用** |

### 通行密钥

| 项目 | 说明 |
| --- | --- |
| 添加 | 填写 **名称**（可选，最多 64 字符），点击 **添加通行密钥**，按浏览器提示完成注册。浏览器不支持 WebAuthn 时按钮不可用 |
| 删除 | 在列表中删除，需确认 |
| 登录 | 登录页 **使用通行密钥登录**；不再进入两步验证步骤 |
| 绑定 | 通行密钥绑定 `EDGEWEIR_PUBLIC_URL` 的主机名；更换控制台主机名后，已注册的通行密钥无法使用 |

### 会话

| 项目 | 说明 |
| --- | --- |
| 退出 | 侧边栏底部用户菜单 → **退出登录** |
| 有效期 | 7 天；使用期间每 24 小时最多顺延一次（better-auth 默认值） |
| 登录限速 | 登录与修改密码：每个客户端 IP 每 10 秒 3 次，生产环境（`NODE_ENV=production`）启用。客户端 IP 的取值见 [可信代理与客户端 IP](../deploy/networking.md#可信代理与客户端-ip) |
| 停用账户 | 平台管理员停用账户时删除其全部会话；停用期间其 AccessKey 调用被拒绝 |

登录（含失败）、修改密码、启用与停用两步验证、添加与删除通行密钥写入 [审计日志](admin.md#审计日志)。

## 控制台导航

所有用户使用控制台；平台管理员另有后台，见 [平台管理](admin.md#控制台与后台切换)。

| 菜单 | 路径 | 内容 | 可见范围 |
| --- | --- | --- | --- |
| **概览** | `/overview` | 流量统计、流量最高的网站、最近访问 | 全部 |
| **证书** | `/certificates` | 证书与 DNS 凭据，见 [HTTPS 与证书](https.md) | 全部 |
| **网站** | `/sites` | 网站列表与详情 | 全部 |
| **告警** | `/alerts` | 告警订阅与近期告警，见 [域名、DNS 与告警](dns-and-alerts.md) | 全部 |
| **IP 名单** | `/ip-lists` | 组织的 IP 名单，见 [规则、IP 名单与 GeoIP](rules.md) | 全部 |
| **刷新预热** | `/purge` | URL / 目录 / 全站刷新、URL 预热与任务，见 [源站与缓存](origins-and-cache.md) | 全部 |
| **组织成员** | `/members` | 成员、邀请、组织策略 | 所有者、管理员 |
| **账户安全** | `/security` | 密码、两步验证、通行密钥 | 全部 |
| **设置** | `/settings` | 偏好（语言、主题）、AccessKey | 全部 |

| 其他路径 | 说明 |
| --- | --- |
| `/` | 无页面：未初始化跳转 `/setup`，已登录跳转 `/overview`，否则跳转 `/login` |
| `/login` | 登录 |
| `/setup` | 初始化向导，初始化完成后跳转 `/login` |
| `/invite/<邀请 ID>` | 邀请页，无需登录即可打开 |

## 故障排查

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| **需要组织所有者或管理员权限** | 成员角色调用成员管理 | 由所有者或管理员操作 |
| **只有组织所有者可以管理所有者** | 管理员授予、修改或移除所有者 | 由所有者操作 |
| **组织至少需要一个所有者** | 移除或降级最后一个所有者 | 先将其他成员设为所有者 |
| **已经是成员：…** | 被邀请或添加的邮箱已在组织中 | 无需邀请 |
| **邀请不存在或已过期** | 链接超过 7 天，或已被取消、替换或接受 | 重新邀请 |
| **请用 … 登录后接受邀请** | 当前登录账户不是受邀邮箱 | 退出后以受邀邮箱登录 |
| **账号已被停用** | 平台管理员停用了该账户 | 由平台管理员 **启用账号** |
| **组织要求启用两步验证** | 组织策略要求 TOTP | 在 **账户安全** 启用两步验证 |
| **验证已过期，请重新登录** | 两步验证步骤超时 | 重新登录 |
| **请求太频繁，请稍后再试** | 触发登录限速 | 10 秒后重试 |
