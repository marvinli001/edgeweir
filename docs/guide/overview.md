# 概览

控制台首页 /overview：待处理事项、实时指标、全部网站的流量统计、边缘网络地球与节点、发布和最近访问列表。

## 页面结构

页面：**概览**（`/overview`），登录后的默认页面。自上而下：

| 区块 | 内容 | 刷新 |
| --- | --- | --- |
| 欢迎条 | **你好，{姓名}**，按钮 **新建网站**（打开 `/sites` 的新建对话框）与 **添加节点**（打开 `/clusters` 的添加节点对话框） | — |
| **待处理** | 需要处理的集群事项，见 [待处理](#待处理) | 10 秒 |
| **此刻** | 实时指标卡，见 [此刻](#此刻) | 流量 60 秒，节点 10 秒 |
| **统计** | 所选时间范围内全部网站的流量，含 **边缘网络** 卡片，见 [统计](#统计) 与 [边缘网络](#边缘网络) | 60 秒 |
| 列表 | **最近发布**、**最近访问**、**网站**、**节点**，见 [列表](#列表) | 网站 30 秒，其余 10 秒 |

除欢迎条外，每张卡片都可以隐藏，见 [自定义卡片](#自定义卡片)。

## 待处理

列出各集群需要处理的事项，每行显示事项与所属集群，点击打开该集群：DNS 事项打开 **DNS** 页签，升级与金丝雀事项打开 **发布** 页签，其他打开 **节点** 页签。没有事项时不显示。按下表顺序排列。

| 事项 | 状态色 | 打开 |
| --- | --- | --- |
| **异常节点：N** | 错误 | 节点 |
| **DNS 版本 #N 发布失败** | 错误 | DNS |
| **DNS 发布被大面积摘除保护拦截** | 错误 | DNS |
| **升级到 X 失败** | 错误 | 发布 |
| **金丝雀 #N 已回滚** | 错误，带距今时间 | 发布 |
| **金丝雀 #N 待推进** | 警告 | 发布 |
| **金丝雀 #N 观察中** | 警告，带窗口结束倒计时 | 发布 |
| **落后节点：N** | 警告 | 节点 |
| **无公网地址的节点：N** | 警告 | 节点 |

各事项的判定条件见 [待处理](clusters.md#待处理)。

| 卡片 | 值 | 迷你图 |
| --- | --- | --- |

| **出口带宽** | 最近一个完整分钟发往访客的字节数 × 8 / 60，单位 bps–Tbps | 过去 1 小时每分钟出口字节数 |
| **缓存命中率** | 过去 1 小时 `命中 /（命中 + 未命中）`，标注 **过去 1 小时** | 每分钟命中率 |

| 规则 | 说明 |
| --- | --- |
| 数据来源 | 前三张卡片读取 `GET /api/v1/analytics/traffic?range=1h`，与统计同源；正在累计的当前分钟不计入 |

## 统计

全部网站的流量，按所选时间范围统计；与网站 **统计** 页签使用同一组件，网站页签只统计该网站。

### 时间范围与刷新

| 控件 | 说明 |
| --- | --- |
| 时间范围 | **过去 1 小时**、**过去 6 小时**、**过去 24 小时**（默认）、**过去 7 天**、**过去 30 天**；非默认值写入 URL 的 `range` 参数（`1h`、`6h`、`7d`、`30d`） |
| **刷新** | 立即重新读取全部卡片；数据每 60 秒自动刷新，刷新期间保留旧数值并淡化 |
| **自定义卡片** | 见 [自定义卡片](#自定义卡片) |

| 时间范围 | 数据点间隔 | 数据来源 | 保留期 |
| --- | --- | --- | --- |
| 过去 1 小时 | 1 分钟 | 节点每分钟统计 | 7 天 |
| 过去 6 小时 | 5 分钟 | 节点每分钟统计 | 7 天 |
| 过去 24 小时 | 10 分钟 | 节点每分钟统计 | 7 天 |
| 过去 7 天 | 1 小时 | 每小时汇总 | 90 天 |
| 过去 30 天 | 6 小时 | 每小时汇总 | 90 天 |

统计来自节点每分钟上报的 `ReportStats` 计数（按节点与网站），存入 PostgreSQL；与[访问日志](access-logs.md)的采样无关。

### 指标卡片

| 卡片 | 值 | 变化方向 |
| --- | --- | --- |
| **请求总数** | 范围内的请求数 | 上升为好 |
| **数据传输** | 范围内发往访客的字节数 | 上升为好 |
| **缓存命中率** | `命中 /（命中 + 未命中）`；未缓存的请求不计入 | 上升为好 |
| **带宽峰值** | 流量最大的数据点的出口带宽 | 上升为好 |
| **4xx 占比** | 4xx 响应 / 请求总数 | 下降为好 |
| **5xx 占比** | 5xx 响应 / 请求总数 | 下降为好 |

每张卡片显示 **较上一时段 {变化}**：与紧邻的等长时段比较；上一时段为 0 时不显示。点击卡片或图表打开 **{指标}详情** 对话框：

| 指标 | 详情视图 |
| --- | --- |
| **请求总数** | **按网站划分的请求总数**、**按节点划分的请求总数**、**按状态码划分的请求** |
| **数据传输** | 按网站、按节点划分的数据传输 |
| **缓存命中率** | **按缓存状态划分的请求**：**命中**、**未命中**、**未缓存** |
| **带宽峰值** | 按网站、按节点划分的带宽 |
| **4xx 占比** / **5xx 占比** | 该类状态码的 **状态码排行** |

详情视图显示前 10 项的趋势，其余合并为 **其他**；网站统计页签中没有按网站划分的视图。

### 状态码、排行与地区

| 卡片 | 内容 |
| --- | --- |
| **状态码** | 2xx、3xx、4xx、5xx 的请求数与占比；点击打开 **按状态码划分的请求** |
| **请求最多的网站** | 前 5 个网站，点击打开网站 |
| **请求最多的节点** | 前 5 个节点，点击打开节点所在集群 |
| **流量最高的国家** | 按发往访客的字节数排列的前 5 个国家 |
| **热门 URL（估算）** | 节点预聚合的高频 URL，近似值；概览中没有行操作，网站页签中每行的菜单为 **刷新 URL** |
| **热门 IP（估算）** | 节点预聚合的高频访客 IP，近似值；每行的菜单 **封禁 IP**（概览中为全局封禁，网站页签中为该网站的封禁），见 [封禁](bans.md) |

没有流量的卡片显示 **暂无流量**。

## 边缘网络

位于两张大图表旁（窄屏时在其下方）。

| 部分 | 内容 |
| --- | --- |
| 标题行 | **边缘网络**、全部在线节点的出口带宽合计、**实时** 标记 |
| 地球 | 每个位置一个标记，大小按该位置的节点数，颜色按该位置最差的状态 |
| 位置列表 | 每个集群的每个区域一行：区域名（节点没有区域时为集群名）、集群名、状态文字、**N/M 在线**、出口带宽；点击打开该集群。没有节点时显示 **暂无节点** |

地球标记的位置：

| 规则 | 说明 |
| --- | --- |
| 定位地址 | 控制台在心跳应答中指定：节点第一个公网调度地址，没有时为节点连接来源的公网地址 |
| 查询 | 节点用自己的 GeoIP 库查询定位地址，在下一次心跳中上报国家、一级行政区与经纬度（经纬度需要 City 库） |
| 坐标 | 有经纬度时使用经纬度；只有国家时使用国家的中心点；查不到国家的节点不显示在地球上 |
| 合并 | 经纬度保留 1 位小数后相同的节点合并为一个标记，悬停显示 `{地区} · {N} 个节点`；单个节点显示 `{节点名} · {地区}` |
| 版本要求 | 节点 v1.6.2 起上报位置；更早的节点不显示在地球上，仍出现在位置列表中 |
| 范围 | 只含已启用的节点 |

状态（标记颜色与位置列表的状态文字）：

| 状态色 | 条件 | 状态文字 |
| --- | --- | --- |
| 正常 | 全部节点在线、数据面正常、运行目标版本 | — |
| 警告 | 部分节点数据面异常 | **数据面异常** |
| 警告 | 部分节点离线 | **离线** |
| 警告 | 有在线节点未运行目标版本 | **落后** |
| 错误 | 没有在线且数据面正常的节点 | **数据面异常** 或 **离线** |

节点的定位地址、调度地址与 GeoIP 库见 [调度地址与备用 IP](scheduling.md#调度地址与备用-ip) 与 [GeoIP 数据库](system.md#geoip-数据库)。

## 列表

| 列表 | 内容 | 点击 |
| --- | --- | --- |
| **最近发布** | 全部集群最近的 5 个配置版本：版本号、原因、距今时间；没有时为 **暂无发布** | 打开该集群的 **发布** 页签 |
| **最近访问** | 本浏览器中最近打开的 5 个页面或网站页签，按账户分别保存在浏览器本地存储；没有时为 **暂无记录** | 打开该页面 |
| **网站** | 网站总数；先列已加星标的网站，再按创建时间列出，共 5 个；没有网站时为 **暂无网站** 与 **新建网站** | 打开网站；标题打开 **网站** 列表 |
| **节点** | **N/M 在线**；按状态排序的 5 个节点：名称、已应用版本、状态；没有节点时为 **暂无节点** 与 **添加节点** | 打开节点所在集群；标题打开 **集群与节点** |

**节点** 列表的状态，按排列顺序：

| 状态 | 条件 |
| --- | --- |
| **离线** | 连接过节点通道，当前离线 |
| **应用失败** | 最近一次应用配置失败 |
| **数据面异常** | 在线，已应用配置，数据面不健康 |
| **落后** | 已应用版本低于目标版本（金丝雀期间非金丝雀节点的目标为稳定版本） |
| **待应用配置** | 在线，尚未应用任何配置 |
| **等待心跳** | 已注册，尚未连接节点通道 |
| **已停用** | 节点已停用 |
| **已同步** | 运行目标版本 |

## 自定义卡片

**统计** 标题行的 **自定义卡片** 菜单按组列出概览的全部卡片，取消勾选即隐藏；**恢复默认** 显示全部卡片。

| 组 | 卡片 |
| --- | --- |
| **此刻** | **请求速率**、**出口带宽**、**缓存命中率**、**在线节点** |
| **统计** | **请求总数**、**数据传输**、**边缘网络**、**缓存命中率**、**带宽峰值**、**4xx 占比**、**5xx 占比**、**状态码**、**请求最多的网站**、**请求最多的节点**、**流量最高的国家**、**热门 URL（估算）**、**热门 IP（估算）** |
| **列表** | **最近发布**、**最近访问**、**网站**、**节点** |

| 规则 | 说明 |
| --- | --- |
| 保存位置 | 随账户保存在控制台，换浏览器后不变；不写审计 |
| 范围 | 概览与网站 **统计** 页签各有一份；网站页签的设置对全部网站生效 |
| 新卡片 | 以后版本新增的卡片默认显示 |
| 隐藏后 | 卡片不再查询数据；统计卡片全部隐藏时显示 **卡片已全部隐藏** 与 **全部显示** |

## 接口

| 数据 | 接口 |
| --- | --- |
| 计数、最近 10 个配置版本、待处理事项 | `GET /api/v1/overview` |
| 流量序列与合计（含上一时段） | `GET /api/v1/analytics/traffic?range=&siteId=` |
| 请求最多的网站 / 节点 | `GET /api/v1/analytics/top-sites`、`GET /api/v1/analytics/top-nodes`（`range`，`limit` 1–50，默认 5） |
| 详情对话框的分项 | `GET /api/v1/analytics/breakdown`（`by`：`site`、`node`、`status`、`block_reason`；`metric`；`statusClass`；`limit` 1–20，默认 10） |
| 热门 URL / IP | `GET /api/v1/analytics/top-requests`（`by`：`url`、`ip`；`limit` 1–50，默认 10；结果标记 `approximate`） |
| 国家等维度 | `GET /api/v1/analytics/dimensions` |
| 隐藏的卡片 | `GET /api/v1/hidden-cards`、`PATCH /api/v1/hidden-cards` |
| 节点（含 `location`） | `GET /api/v1/nodes` |

`range` 取值 `1h`、`6h`、`24h`、`7d`、`30d`，默认 `24h`。字段见 [API 参考](../reference/api.md)。

## 故障排查

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| 统计全部为 0 或 **暂无流量** | 没有请求经过节点，或节点没有上报统计 | 确认节点 **在线** 且网站已生效；用 `curl --resolve` 直接请求节点，见 [快速上手](first-site.md#6-验证) |
| **缓存命中率** 为 0 | 没有缓存规则覆盖请求，或源站响应不可缓存（计为 **未缓存**，不计入比例） | 检查网站的缓存规则与源站 `Cache-Control`，见 [源站与缓存](origins-and-cache.md) |
| 节点不在地球上 | 节点早于 v1.6.2、没有公网地址，或 GeoIP 库查不到该地址 | 升级节点，见 [节点升级](node-upgrades.md)；配置公网调度地址；更新 GeoIP 库 |
| 节点在地球上的位置偏差大 | 只有国家库时按国家中心点定位；GeoIP 库的位置不准确 | 使用含经纬度的 City 库 |
| **流量最高的国家** 为空，其他卡片有数据 | 节点版本较旧，不上报维度统计 | 升级节点 |
| **最近访问** 为空 | 浏览器禁用了本地存储，或换了浏览器 | — |
