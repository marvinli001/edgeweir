集群、节点组、节点与区域，配置版本与配置金丝雀，网站启停与待处理事项。

## 集群

集群是一组节点与分配到这些节点的网站和 L4 应用；每个集群有独立的配置版本序列。

| 操作 | 位置 | 说明 |
| --- | --- | --- |
| **新建集群** | 页面操作 | **集群名称**：小写字母、数字与 `-`，以字母或数字开头，最多 64 字符，不能重复；**描述**：最多 500 字符。创建时生成默认节点组 `default` 并发布版本 #1 |
| **编辑集群** | 概要的 **⋯** | 修改名称与描述 |
| **删除** | 概要的 **⋯** | 集群没有节点和网站，DNS 不是 **自动**，且已写入的 DNS 记录清理完成时允许 |

| 规则 | 说明 |
| --- | --- |
| 网站所在集群 | 有多个集群时，新建网站的表单可选择「集群」（默认最早创建的集群）；`/api/v1` 用 `clusterId` 指定。网站创建后不能更换集群 |
| 容量 | 一个集群最多发布 512 个已启用的网站（`CLUSTER_SITE_LIMIT`），最多 256 个 [L4 应用](l4.md)（`L4_APP_LIMIT`） |
| 缓存区 | **设置** 页签的「缓存区」卡片设置每个节点缓存区的容量与不活跃回收时间，见 [缓存区](origins-and-cache.md#缓存区) |

## 节点组

**节点** 页签的节点组表：**节点组**（默认节点组标 **默认**，金丝雀组标 **金丝雀**）、**区域**（「名称 · 代码」，未设置为「—」）、**节点数**。

| 操作 | 说明 |
| --- | --- |
| **新建节点组** | **节点组**：名称，最多 64 字符，集群内唯一；**区域**：可选，见 [区域](#区域)；**金丝雀组**：见 [配置金丝雀](#配置金丝雀) |
| **编辑节点组** | 点击节点组所在行打开；修改名称、区域与 **金丝雀组** |
| 删除 | 行末 **⋯** 中的 **删除**，确认「删除节点组 {name}？其中的节点移回默认组」。默认节点组没有 **⋯**，不能删除 |

节点组用于 DNS 绑定的线路与 [备用节点组](dns.md#备用节点组)、[节点升级](node-upgrades.md) 与 [配置金丝雀](#配置金丝雀) 的金丝雀组。节点组的区域是其中节点 [兼任探针](scheduling.md#节点兼任探针) 时所在的区域。

## 添加节点

**添加节点** 对话框打开即生成一次性安装命令：集群的默认节点组，有效期 1 小时，不带节点名称。**选项** 显示下列字段，**重新生成** 按所填的值生成新的命令。

| 字段 | 说明 |
| --- | --- |
| **节点名称** | 可选，最多 64 字符 |
| **节点组** | 默认为集群的默认节点组；集群只有一个节点组时不显示 |
| **有效期** | 15 分钟、1 小时（默认）、24 小时；API 允许 5 分钟至 7 天 |

| 项目 | 说明 |
| --- | --- |
| **安装命令** | 带剩余时间，仅显示一次；每次打开对话框生成新的 token，关闭后不再显示 |
| token | `ewt_` 开头，单次有效；数据库保存 SHA-256 与前缀，不保存明文 |
| CA 指纹 | 命令的 `--ca-sha256`，与 [系统信息](system.md#系统信息) 的 **CA 指纹** 相同 |
| 连接检查 | 一行节点通道连接检查；未通过时带「修改」链接，打开 **系统设置**（[节点通道](system.md#节点通道)） |
| **注册进度** | 等待节点注册 → 已注册 → 配置已应用 → 数据面正常 → 有可供 DNS 使用的地址；token 过期时为「令牌已过期」 |

地址提醒、连接检查与安装流程见 [接入节点](../deploy/nodes.md)。

## 节点

**节点** 页签的节点表每个节点一行，可按 **节点**、**节点组**、**出口带宽**、**已应用版本** 与 **心跳** 排序（`?sort=`）。**出口带宽** 列在宽度不足 `lg` 时隐藏，**Agent / 引擎** 与 **心跳** 列在不足 `xl` 时隐藏。集群没有节点时显示「暂无节点」与 **添加节点**。

| 列 | 内容 |
| --- | --- |
| **节点** | 名称与第一个 IP（悬停显示主机名）；兼任探针的节点另标 **兼任探针** |
| **状态** | **在线**（45 秒内有心跳）、**离线**、**已停用**；注册后还没有连接过节点通道的节点为 **等待心跳**；在线但数据面不健康时另标 **数据面异常**；节点通道拒绝离线节点的证书时标 **证书已过期** 或 **证书被拒绝**；DNS 没有可用地址时另标 **无公网地址**，见 [没有公网地址的节点](scheduling.md#没有公网地址的节点) |
| **节点组** | 节点组与区域 |
| **负载** | CPU 与内存使用率（`metrics-v1`），75% 起带警告色圆点，90% 起带错误色圆点；离线或没有指标时为「—」 |
| **出口带宽** | 节点上报的出口带宽 |
| **已应用版本** | `#N`，标 **已同步**（达到该节点的目标版本）、**落后**、**应用失败**（悬停显示原因）或 **需要升级**；在线但还没有应用任何配置时标 **待应用配置**；节点上报证书加载失败时另标「N 张证书未加载」（悬停显示证书名） |
| **Agent / 引擎** | agent 版本，需要时标 **建议升级**；还没用上当前的 [节点通道地址](system.md#节点通道) 时另标 **未切换**、**无法切换**（悬停显示原因）、**用备用地址** 或 **需升级才能切换**（v1.2.0 以前的节点） |
| **心跳** | 最近一次心跳距今多久，悬停显示具体时间 |

### 节点详情

点击节点所在行，或行末 **⋯** 的 **详情**（`/clusters?node=<节点 ID>`）。页签 **概况** 与 **日志**（`?nodeTab=logs`，见 [节点日志](node-logs.md)）。

| 项目 | 内容 |
| --- | --- |
| **节点组** | 节点组与区域 |
| **已应用版本** | 应用失败时标 **应用失败** |
| **Agent / 引擎** | agent 版本、引擎及其版本，需要时标 **建议升级** |
| **心跳** | 最近一次心跳距今多久 |
| **时钟偏差** | 最近一次上报的值：「一致」「快 N 秒」「慢 N 秒」；达到 [告警规则](alerts.md#设置告警规则) 的 **时钟偏差（秒）** 时标 **偏差过大** |
| **IP** | 最近一次心跳上报的全部单播地址，最多 64 个；心跳没有上报地址时保留原值。DNS 与探针使用的地址见 [调度地址与备用 IP](scheduling.md#调度地址与备用-ip) |
| **指标** | CPU 与内存的用量条（75% 起警告色，90% 起错误色）、1 / 5 / 15 分钟负载、出口带宽与活动连接；没有指标时为「暂无指标」 |
| **数据面** | 正常 / 数据面异常 |
| **连接来源地址** | 节点连接控制台时的源地址 |
| **节点通道** | 在用的地址及其标记、无法切换或改用备用地址的原因、保留的备用地址 |
| **证书到期** | 客户端证书（30 天，剩余不足三分之一时节点自动续期）；不足 10 天标 **即将到期**；过期或被节点通道拒绝时标 **证书已过期** 或 **证书被拒绝** |
| **兼任探针**、**调度地址**、**探测结果** | 见 [区域探针与智能调度](scheduling.md) |
| **缓存** | 缓存用量与本节点的容量设置，见 [缓存区](origins-and-cache.md#缓存区) |

| 操作 | 说明 |
| --- | --- |
| **详情** | 见 [节点详情](#节点详情) |

## 配置版本

影响节点配置的变更在集群内发布一个新版本；内容哈希与上一版相同时不发布。**发布** 页签的 **配置版本** 表列出最近 20 个版本：**版本**、**内容哈希**、**网站**、**原因**、**时间**；除最新版本外每行有 **回滚**。

| 项目 | 值 |
| --- | --- |
| 保留 | 每个集群最近 200 个版本，每小时清理；金丝雀的稳定版本与候选版本不清理 |
| ACME HTTP-01 | 只为 HTTP-01 挑战发布的版本不计入保留数，1 小时后删除 |
| 版本号 | 「库中最新版本号」与「本集群节点已应用的最高版本号」中较大者加一；数据库从备份恢复后不回退 |

| 原因 | 触发 |
| --- | --- |
| 创建集群 {集群} | 新建集群 |
| 新建网站 / 修改网站 / 删除网站 {网站} | 网站变更 |
| 启用网站 / 停用网站 {网站} | [网站启停](#网站启停) |
| 启用 / 停用 / 删除 {N} 个网站 | 网站列表的批量操作，见 [批量操作](site-management.md#批量操作) |
| 把 {源} 的设置复制到 {网站} / 从 {源} 克隆网站 {网站} | [复制设置](site-management.md#复制设置) 与 [克隆网站](site-management.md#克隆网站) |

| 清除网站 {网站} 的缓存 | 旧版控制台的网站清除缓存；现在整站刷新是节点任务，不发布版本 |

### 回滚

**回滚** 确认「以 #{版本} 的配置发布新版本？」后，以所选版本的内容发布一个新版本，不删除历史，写审计 `cluster.rollback`。

| 项目 | 行为 |
| --- | --- |
| 取当前值 | IP 名单、全局规则、全局 Under Attack 与源站地址允许清单 |
| 不下发 | 当前已停用的网站与 L4 应用 |
| 拒绝 | 所选版本引用的网站、域名、证书、IP 名单或 L4 应用已删除，L4 应用的端口已不在端口池内，或证书已过期（`ROLLBACK_RESOURCE_UNAVAILABLE`） |
| 预览 | 确认对话框列出相对最新版本 **新增**、**修改**、**移除** 的网站；内容相同时为「与当前版本相同」，只有网站以外的配置不同时为「网站无变化」；不能回滚时显示原因，确认按钮不可用。预览不写入数据，API 见 [集群与概览](../reference/api/clusters.md#集群) |
| 金丝雀 | 回滚直接到全部节点；进行中的金丝雀结束，结果为「手动回滚」 |

### 节点能力

变更需要集群活动节点缺少的能力时：

| 发布方 | 行为 |
| --- | --- |
| 控制台账户（会话或 AccessKey） | 照常发布；缺少能力的节点显示 **需要升级**，继续使用原配置 |
| 服务账号 | 409 `NODE_CAPABILITY_REQUIRED`，不发布 |
| 控制台的自动任务 | 不发布 |

## 配置金丝雀

**发布** 页签的 **配置金丝雀** 卡片按集群设置策略，并显示当前发布。默认关闭。

| 策略字段 | 取值 | 默认值 |
| --- | --- | --- |
| **启用金丝雀** | 开 / 关 | 关 |
| **观察窗口（分钟）** | 1–60 | 5 |
| **5xx 比例倍数（相对基线）** | 1–100 | 2 |
| **5xx 比例下限（%）** | 0.1–100 | 5 |
| **最小请求数** | 1–1000000 | 100 |
| **通过后自动推进** | 开：窗口通过后推进到全部节点；关：等待 **立即推进到全部** | 开 |

金丝雀组在 [节点组](#节点组) 的 **金丝雀组** 开关设置。

| 项目 | 行为 |
| --- | --- |
| 金丝雀节点 | 窗口开始时在线、属于金丝雀组的已启用节点。窗口结束前不变：期间离开金丝雀组的节点仍是金丝雀节点，新加入的节点等下一个窗口 |
| 目标版本 | 金丝雀节点取候选版本，其他节点取稳定版本；节点只拿到自己的目标版本 |
| DNS | 每个节点按自己的目标版本判断；窗口期间非金丝雀节点不被摘除 |
| 5xx 统计 | 节点按整分钟上报。每个金丝雀节点从应用候选版本后的下一个整分钟算起，应用之前的请求（含同一分钟内的）不计入；非金丝雀节点从其中最早的一分钟算起 |
| 窗口结束 | 观察窗口时长已过，且金丝雀节点已上报窗口内每一分钟与候选版本至少一个整分钟的统计；统计迟到时最多再等 2 分钟，按已到的数据判定。请求数不足最小请求数（含没有流量）时不按 5xx 判定 |
| 回滚条件（窗口内任一条） | 金丝雀节点应用失败；数据面不健康或离线；金丝雀节点的 5xx 比例超过 max(非金丝雀节点的 5xx 比例 × 倍数, 下限)，且金丝雀请求数不少于最小请求数；窗口结束后超过一个窗口仍未应用 |
| 回滚动作 | 以稳定版本的内容发布一个新版本，所有节点回到该内容；窗口内停用、删除的网站与移除的域名不带回，缓存代数与证书取当前值；写审计（操作者 **系统**），并发送告警「配置金丝雀发布已回滚」，见 [集群与 DNS 告警](alerts.md#集群与-dns-告警) |
| 回滚后 | 集群停在稳定版本；数据库中的改动不撤销，之后的发布仍先经过金丝雀 |
| 窗口期间有新发布 | 新候选版本取代旧候选版本，窗口开始时间与金丝雀节点不变；只统计新候选版本的流量；窗口末尾才应用的候选版本把窗口延长到它的第一个整分钟结束 |
| 候选版本撤回 | 新发布的内容与稳定版本相同时，金丝雀结束，结果为「候选版本已撤回」 |
| 没有在线的金丝雀节点 | 直接发布到全部节点，写审计 `cluster.rollout_direct` 并发送告警，不阻塞发布 |
| 直接到全部节点的变更 | ACME HTTP-01 挑战；停用、删除网站与移除域名；停用、删除 L4 应用；调低访问日志采样率；证书续签；挑战密钥轮换；网站与全局的 Under Attack。这些变更同时进入稳定版本，其余改动仍在候选版本中等待窗口。[回滚](#回滚) 也直接到全部节点 |
| 关闭策略 | 进行中的候选版本推进到全部节点 |

| 状态 | 含义 |
| --- | --- |
| **未进行** | 没有候选版本 |
| **金丝雀中** | 候选版本在金丝雀节点上观察 |
| **待推进** | 窗口已通过，等待手动推进 |
| **已推进** | 候选版本已是全部节点的版本 |
| **已回滚** | 金丝雀节点已回到稳定版本 |
| **已直接发布** | 没有在线的金丝雀节点，变更已直接发布 |

| 卡片内容 | 说明 |
| --- | --- |
| 状态与结果 | 当前状态与上一次发布的结果：自动推进、手动推进、金丝雀节点应用失败、金丝雀节点未能按时应用、金丝雀节点不健康、5xx 比例超过阈值、手动中止、没有在线的金丝雀节点、策略已关闭、手动回滚、候选版本已撤回 |
| **稳定版本** / **候选版本** | 版本号 |
| **上一个候选版本** | 上一次回滚或推进的候选版本与距今时间 |
| **改动** | 发布进行中时，候选版本相对稳定版本 **新增**、**修改**、**移除** 的网站；网站没有变化时为「网站无变化」 |
| **原因** | 稳定版本之后各版本的发布原因，不重复 |
| **窗口结束** | 倒计时，悬停显示具体时间 |
| **金丝雀流量** / **基线流量** | 「N 个请求，M 个 5xx」 |
| **金丝雀节点** | 每个金丝雀节点的已应用版本，参与本窗口的标 **参与窗口**；没有时为「没有金丝雀节点」 |

**立即推进到全部**（确认「把版本 #{版本} 推进到全部节点？」，审计 `cluster.rollout_promote`）与 **中止并回滚**（确认「中止版本 #{版本} 的金丝雀并回滚？」，审计 `cluster.rollout_abort`）只在 **金丝雀中** 与 **待推进** 时可用。策略修改写审计 `cluster.rollout_policy_update`。

## 区域

页面：**集群与节点** 的 **区域** 视图（`/clusters?view=regions`；`/regions` 跳转到这里），页面操作为 **新建区域**。区域是节点组与区域探针的地域标签（如华东），在节点组表与节点表中显示；探测指标的调度条件可以只计一个区域的探测方。探针在 **系统设置** 的 **监控** 页签，见 [区域探针](scheduling.md#区域探针)。

列表上方的点阵地图标出区域，按代码或名称中的城市定位（如 `ap-tokyo`、东京）；识别不出城市的区域只在列表中显示，一个也识别不出时不显示地图。

| 操作 | 说明 |
| --- | --- |
| **新建区域** | **名称**：最多 64 字符；**代码**：小写字母、数字与 `-`，以字母或数字开头，最多 32 字符，不能重复 |
| **编辑区域** | 点击区域所在行打开；修改名称与代码 |
| 删除 | 行末 **⋯** 中的 **删除**；区域下还有探针时拒绝（「该区域下还有 N 个探针」）；引用该区域的节点组保留，区域置空，其中兼任探针的节点不再探测 |

## 网站启停

网站 **概览** 页签的 **状态** 旁有 **停用** / **启用**（需要确认）；API 见 [网站启停](../reference/api/sites.md#网站启停)。

| 项目 | 行为 |
| --- | --- |
| 状态 | **网站** 列表的 **状态** 列与网站 **概览** 页签：**待接入**（集群没有在线节点，或在线节点都还没有应用含该网站的版本）、**生效中 N/M**（M 个在线节点中 N 个运行该网站的最新配置且数据面正常）、**运行中**（全部在线节点都已运行）、**已停用**。[配置金丝雀](#配置金丝雀) 窗口内为「金丝雀 N/M，HH:MM 全部生效」；策略关闭了 **通过后自动推进** 时为「金丝雀 N/M，待推进」。网站的 [用量保护](usage-protection.md) 动作生效时另标 **用量超限**。未全部生效时页面每 5 秒刷新 |
| 提示 | 保存、新建、启用与停用网站后的提示随节点更新：**生效中 N/M** → **已生效**（金丝雀中显示窗口结束时间；停用为 **移除中 N/M** → **已从节点移除**；集群没有在线节点时为「没有在线节点」），最多跟踪 3 分钟 |
| 节点 | 停用的网站不下发；节点对其域名的 HTTP 请求返回 503（`X-Edgeweir-Error: site-disabled`），页面为 [平台错误页](system.md#平台错误页) 的 **网站已停用** 或内置页面；HTTPS 请求在 TLS 握手时失败 |
| DNS | 记录保留 |
| 证书 | 续期继续，HTTP-01 挑战照常应答 |
| 刷新预热 | 返回 `SITE_DISABLED` |
| 回滚 | 不会让已停用的网站重新下发 |
| 版本与审计 | 状态变化时发布新版本并写审计（`site.enable`、`site.disable`）；状态不变时不发布、不写审计 |

**概览**（`/overview`）顶部的 **待处理** 列出需要处理的事项，每行显示所属集群；没有事项时不显示。侧边栏 **概览** 旁显示事项数，顶栏的告警图标带红点。按下表顺序排列：

| --- | --- | --- |
| **异常节点：N** | 已启用、连接过节点通道的节点：离线、应用失败、数据面异常（已应用过配置时），或节点通道拒绝其证书 | 集群 |
| **DNS 版本 #N 发布失败** | 集群的 DNS 不是 **不管理**，DNS 版本发布失败 | **DNS** 页签 |
| **DNS 发布被大面积摘除保护拦截** | 集群的 DNS 发布被 [大面积摘除保护](dns.md#大面积摘除保护) 拦下 | **DNS** 页签 |

| **金丝雀 #N 已回滚** | 配置金丝雀已回滚，24 小时内；显示距今时间 | **发布** 页签 |
| **金丝雀 #N 待推进** | 窗口已通过，等待 **立即推进到全部** | **发布** 页签 |

## 故障排查

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| **集群还有 N 个节点和 M 个网站，不能删除** | 集群非空 | 删除集群内的节点与网站后重试 |
| **先关闭该集群的 DNS，等待记录清理完成** | 集群的 DNS 仍为 **自动** 或仍持有记录 | 在 **DNS** 页签切换到 **不管理**，等待清理完成后重试 |
| **集群名称已存在：…** / **节点组已存在：…** / **区域代码已存在：…** | 名称或代码重复 | 更换名称或代码 |
| **默认节点组不能删除** | 删除默认节点组 | 默认节点组只能改名或更换区域 |
| **该区域下还有 N 个探针** | 删除仍有探针的区域 | 先在 **系统设置** 的 **监控** 页签删除这些探针 |
| **节点组不属于该节点所在的集群** | 跨集群移动节点 | 节点只能在集群内移动；换集群须删除后重新注册 |
| **此集群最多发布 512 个网站** | 集群内已启用的网站达到上限 | 停用不再使用的网站，或经 `/api/v1` 用 `clusterId` 在其他集群新建网站 |
| **节点尚不支持：{能力}（{节点}）** | 服务账号或自动任务发布的变更需要集群活动节点缺少的能力 | 升级节点，见 [节点升级](node-upgrades.md) |
| **回滚引用的资源已移除、转移或不可用**（回滚确认对话框中） | 所选版本引用的网站、域名、证书、IP 名单或 L4 应用已删除，L4 应用的端口不在端口池内，或证书已过期 | 选择更近的版本，或修复当前配置 |
